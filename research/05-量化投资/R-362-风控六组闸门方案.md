## 5. BFF 扩展契约（risk_gates@v2，纯新增）

既有返回键逐字保留；新增 `schema` + 三块：

```jsonc
{
  "schema": "risk_gates@v2",
  "run_date": "2026-08-28",
  "portfolio_dd_gate": {
    "drawdown_pct": 0.0,            // 小数 ≤0；0=新高；4dp
    "peak_nav": 1.00993, "peak_date": "2026-08-28", "as_of": "2026-08-28",
    "band": "lt5",                  // lt5|5_10|10_15|gt15；null=数据不足
    "action": "normal",             // normal|escalated_review|cut_half|circuit_break
    "caliber": "runtime_paper",     // 看板展示口径标注
    "band_source": "target_5_10_15",
    "charter": { "cut_half_at": 0.25, "stop_at": 0.35, "charter_version": "1.0" }
  },
  "vol": {
    "target": 0.08, "band_pp": 0.02,
    "realized": null,               // 20 交易日滚动年化 4dp；不足窗口 → null
    "window_days": 20, "obs_count": 11,
    "in_band": null,
    "status": "insufficient_obs"    // ok | insufficient_obs | unavailable
  },
  "correlation": {
    "pair": "equity_sleeve_vs_hedge_sleeve_gold",
    "method": "pearson_rolling", "window_days": 20,
    "corr": null, "corr_prev_5d": null,
    "flag_level": null,             // 0|1|2|3
    "flag_label": null,             // normal|watch|defensive_cut|escalated_review
    "thresholds": { "t1": 0.75, "t2": 0.85, "t3": 0.90 },
    "status": "insufficient_data",  // ok | insufficient_obs | unavailable | insufficient_data
    "note": "gold 腿日频收益序列待 HP 产物（T3）；三档阈值结构先行展示"
  }
}
```

- **单位**：全部小数（0.08=8%，回撤 ≤0），前端负责 ×100。
- **降级语义（三态+一特例）**：`ok` / `insufficient_obs`（序列存在窗口不满，如 vol 11/20）/ `unavailable`（源文件缺失，同 nav-series 降级 null）/ `insufficient_data`（生产者不存在，如相关性）。降级下数值字段=null、响应仍 200；前端灰显+进度文案（「窗口积累中 11/20」），杜绝空白。
- **路由包装**：维持现有 `ledgerDerived(riskGatesHandler)` 不动（行为最小变化）；解耦账本 503 列为实施选项，默认不动。
- **实现要点**：纯 Node 内置（CSV→数组→running max/rolling std/rolling corr，O(n)），零新依赖；测试 ≥5 例（四带边界 0.049999/0.05/0.10/0.15、insufficient_obs、源缺失降级、charter 注入、旧键逐字不变回归）。
