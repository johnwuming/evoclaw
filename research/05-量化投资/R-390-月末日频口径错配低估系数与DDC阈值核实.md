# R-390：月末 vs 日频口径错配——低估系数矩阵、采样频率标注规范与 DDC 阈值核实

- **任务号**：task-0607（P0，用户 2026-08-31 19:54 定为最高优先级）
- **日期**：2026-08-31
- **定位**：本报告决定所有回撤类数字的可信度口径；为 09-01 决策提供依据。
- **前置**：R-388（runtime 真实回撤审计）已证 a13+现金配置月末采样 MDD −10.34% vs 日频 −21.31%（2.06 倍）；R-389 已闭合两腿基线 6.94pp 分歧并区分金腿实例。本报告在其上补齐静态 58/42 两腿系数、固化标注规范、核实 DDC 阈值。

## 一、背景

风控阈值（DDC、vol_target 8%）全部按**日频逐日判定**逻辑设计，但历史评估（0602/R-388 之前的基线表、看板展示曲线）一律用**月末采样**路径。月末采样天然跳过月内深回撤，系统性低估回撤深度——已证 2.06 倍（a13+现金）。用户裁定：①补齐静态 58/42 两腿系数；②把采样频率写进标注规范；③核实「sleeve 回撤 ≤−20% → 减半」与代码/文档 ddc15 命名是否一致。

**口径声明（必须随数字传播）**：静态 58/42 两腿日频行为**静态权重+原始价格收益的重建路径，非在役信号路径**；对应 R-389 组合实例表 A1 行（A 58% + gold_ret 裸黄金 B&H）的日频延伸。金腿=腾讯公开接口 sh518880 前复权日线 2013-07-29→2026-08-31（3184 行）本地重建，逐日收益取收盘价；58% a13 腿=在役 a13 策略日频净值；每月初再平衡至 58/42，月内权重不漂移。展示口径（A+gold 引擎净值，R-389 设计组合）月末 MDD −9.69% **无日频版本**（shadow_nav 仅月频），故不可与日频数字并列——这正是本次规范要堵的洞。

**三重交叉验证**：①金腿月末 MDD −23.899% 与 R-389 L23 gold_ret −23.90% 独立源逐位一致（6 月单月 −10.85% == R-389 −10.84%）；②a13 腿月末 −16.954% 与 0602 legA 逐位一致；③58/42 月末 −16.39% ≈ R-389 A1 −16.54%（窗口起点 2013-07-29 vs 2013-08、月内再平衡实现细节差 0.15pp）。

**矩阵结论**：低估系数随组合中高波动资产（a13 类权益策略）占比上升而放大（金 1.28 → 两腿 1.40 → a13+现金 2.06 → a13 单腿 1.98-2.0）。两个结构性事实：①月末采样不仅压浅深度，还会**换窗**——58/42 月末口径最深段是 2026 金价慢跌（−16.39%），日频口径最深段是 2015 股灾月内崩塌（−22.88%），月末采样直接看不见后者；②对回撤体验的任何直觉（「组合最多回撤 X%」）在月末口径下不可用于风控判断。

## 三、DDC 阈值核实结论

**用户口径「sleeve 回撤 ≤−20% → 减半」与现行设计一致，核实通过。**「ddc15」命名不构成矛盾，属历史候选名。

- **现行权威定义（sleeve 级 DDC）**：腿 NAV 对自身 running_max，回撤 ≤−20% → 仓位 ×0.5（减半）；自谷底收复 ≥−5%（回补 5%）→ 恢复。参数名 `ddc_th20_rd50_rc5`，原样保留于 sleeve 版本对象。出处：**R-336 §4.4「sleeve 级 ddc」行**、R-362 sleeves_ddc 行（引 R-336 §4.4 sleeve 行）、R-318 §六（「现按 F6 拍板用 dd_thresh=0.20」）。执行语义为日频：T 收盘判定、T+1 生效（R-318 行 22）。
- **ddc15 溯源**：R-243 A15 组件批阈值敏感性候选（ddc15/20/25 = 0.15/0.20/0.25），R-284 档位评估 ddc15 胜出（score 0.8834）但因 paper_engine 无 ddc 代码路径实施阻断、从未上岗；F6 拍板（R-318）后现行阈值定为 **0.20**，ddc15 已被取代，不再是现行口径。
- **易混项区分（回撤四带 ≠ sleeve DDC）**：回撤四带是**组合级**呈现带（R-336 §4.4/R-342 §3.1）：<5% normal / 5-10% escalated_review / 10-15% cut_half / >15% circuit_break；裁决顺序 v1.1：熔断硬上限（单腿 ddc>20% 或组合回撤>15%）> 组合级裁决 > 单腿级裁决。
- **对 −21.31% 的判定**：sleeve DDC 观测对象是 a13 腿 NAV——日频 MDD **−33.55%**，深度击穿 −20% 阈值（超阈 13.55pp）；而月末采样 −16.95% **根本不触发**。若误按 ddc15（0.15）口径理解，月末 −16.95% 仅浅击穿 1.95pp。−21.31%（a13+现金 60/40 组合路径日频 MDD）作辅助口径同样击穿 −20%（超阈 1.31pp）。
- **口径错配的实质后果**：DDC 设计为日频逐日判定，但历史评估全用月末采样 → 在月末口径下 DDC「从未触发」，其风控价值被系统性归零；按日频口径，2015 段等多次深击穿本应触发减半。评估风控阈值必须用日频路径。

## 四、规范条文全文（已增补进 PRD §9.4，v1.9）

> 任何报告/看板/汇报材料引用 MDD、年化、波动、夏普等基线绩效数字时，必须同行标注**四要素**：①组合实例 ②统计窗口 ③口径（净/毛、再平衡频率）④**采样频率（日频路径/月末采样）**；缺任一项禁止引用，评审时主 agent 按此 lint。回撤/波动类数字凡未注明采样频率的一律视为月末采样口径并禁止与日频数字直接比较；月末采样回撤引用时须追加「低估系数参考 X 倍」（沿 R-388/R-390 实测：a13+现金 2.06 倍、a13 单腿 1.98 倍、静态 58/42 两腿 1.40 倍）。风控阈值（DDC/vol_target）评估必须用日频路径——DDC 为日频逐日判定设计（R-336 §4.4/R-318），月末采样会系统性掩盖月内击穿。
