## 二、现行迭代流程全景（一轮迭代的完整生命周期）

```
候选设计(批次任务书: 单维度可归因) → 回测(新基建双窗口) → 门禁评估(g1-g6)
  → PASS 自动 activate(R220#8) / REJECT 留痕 → decision-log + ledger 记录
  → registry 版本化(main.json 字节快照) → sync 到 VPS → dashboard 自动呈现
```

1. **候选设计**：每批（IT-A2..A9）对照明确 parent 只改一个维度；g5 经济逻辑在设计阶段预埋；先算通过线（如 DSR 换算）再定候选。ext runner 机制：对 engine.run_backtest 源码字符串级插入 ext 分支后 exec 副本，**引擎文件零改动**。
2. **回测（新基建）**：全量池（含退市，无幸存者偏差）+ 成本模型 v2 + 一字板不可成交 + 审计锁（AUDIT_LOCK_END=2024-06-30）+ ST 区间表（A5 起）；full+locked 双窗口并行产出。
3. **等价校验（EQUIV）**：每批 patch 开关全关复跑 parent，指标必须与基线**逐位一致（diffs={}）**才挂新分支；锚点校验（如 E2 网格锚 MA200_on_f30 ≡ v5h）同机制。
4. **门禁评估/评分**：g1-g6（见 §3.1）；verdict=PASS 且 prev=candidate → **自动 activate**（R-220 #8 已实施，移除人工确认）；REJECT 如实留痕。
5. **记录规范**：decision-log.jsonl（53 条：trigger/action/backup/params/rollback_condition/expected_impact/phash/data_snapshot）+ experiment-ledger.jsonl（83 条：backtest 48 / evaluate 33 / reset 2，experiment_id=IT-批次-序号）。
6. **rollback 安全网**：activate 时冻结 `registry/{version}.main.json.snapshot` 字节快照，rollback 字节级还原；回退条件预写（"激活后回撤超阈值或 paper 显著劣于 endtoend 回测"）。
