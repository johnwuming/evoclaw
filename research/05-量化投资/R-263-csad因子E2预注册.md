## 一、假设

个股相对其同伴群（120 日收益高相关股）的短期分化波动，在剔除截面波动率水平（vol20+vol120 双中性化）之后，仍包含在役选股层未使用的横截面信息：**高残差分化股的次月收益更低**（R-260 实测 v2 残差分组 Q5−Q1 = −1.33%/月，t=−7.21，严格单调）。将其作为排序因子以**负权**（低残差分化优先）纳入在役 ext ranksum 四因子集，应当能改善选股质量并转化为组合年化收益。机制假设：羊群分化度捕捉的是资金分歧与定价偏离的累积压力，这一信息独立于低波动异象（R-260 裁决核心：残差 ICIR −0.601 ≥ 0.25，原始 ICIR 中约四分之三的信息量与波动率族共享但残差部分存活）。该干预是**选股层因子形态**：只改横截面相对排序，不触碰总仓位（择时层 q3z×EW-MA200 原样）、不新增任何仓位门。

## 二、因子定义（正式口径，含中性化）

**正式定义 = 中性化残差，不是原始 csad_sigma20**（R-260 §五.2 裁决附属结论；原始值在引擎中禁用）。

1. **原始指标 feat_csad_sigma20**（沿 R-257 §2.1 口径，全文引用不重述）：
   - 同伴群：每月末（m−1）用滚动 120 交易日日收益相关定群，相关 >0.5 中取最高前 20 只，不足 5 只当月 NaN，月度重算；
   - CSAD_{i,t} = mean_j |ret_{i,t} − ret_{j,t}|（j∈同伴群），当月逐日；
   - feat_csad_sigma20 = CSAD 滚动 20 日 std（窗内需 20 有效日），月末取值。
2. **中性化（R-260 v2 主裁决口径，逐字）**：每月截面 OLS，F_w = a + b1·vol20 + b2·vol120 + e；回归前对 F 与两个 vol 代理各自做 1%/99% winsorize；vol20 = trailing 20 交易日日收益 std（≥15 有效日）、vol120 = r0419 内部口径（市场非 NaN 日 mask + 个股 NaN→0 + std，2006-01 前无市场数据时不加 mask，5 个月，披露）；残差 e 再 1%/99% winsorize + zscore（**W1 标准化**）。
3. **PIT**：t 月因子值只用 t 月末及以前数据（同伴群在 m−1 月末定、CSAD/sigma20 月末截断）；引擎月频调仓用上月因子值作用于 t 月选股，与在役管道同拍。已知固有属性披露：sigma20 跨月边界混合两套同伴群口径（同伴月度换血）。
4. **数据源与锁定**：HP `results/r0419/csad_sigma20_monthly.csv`（596,522 行 × 253 月，**md5 e9ad0b82851126442174f3eda4d2e105**，VPS work/r0419/ 镜像 md5 文件已复核一致）+ HP `results/work/r0422/vol_panel_monthly.csv`（ym/code/vol20/vol120/idio120，**md5 3ad82499f91ad9a678d5704cffb422a0**）。如需重算原始因子，须同口径复现并对拍（沿 R-257 抽验纪律：月度 csv vs 日频 rolling(20).std 月末值 maxdiff≈1e-17）。
5. **NaN 覆盖政策（预登记）**：csad_resid 覆盖 84.5% 的（月×股）（≥5 同伴；IC 截面月均 2350 vs 引擎合格池月均约 2845，R-257 §三.5）。缺失值在 zscore 后**置 0（中性贡献）**再进加权秩和；不得剔除股票、不得插值。实现须保证 w=0 时新项严格贡献 0（NaN 先置 0，IEEE s+0.0≡s，新项追加于求和末位）——G0 结构可逐位对拍的前提。

## 三、干预形态（因子形态，网格预登记）

### 3.1 函数形式

干预对象 = 在役 ext ranksum 排序分数。在役配置 C4（R-253 §二逐参复刻口径）：

```
sort = ext/ranksum：log_mv⁻(1.0) + amt20⁻(1.0) + pb_inv(0.7) + roe(0.3) + e1f10dz 守卫因子(λ_e1=1.0, deadzone 0.30)
```

干预 = 因子表新增第 5 个选股因子列 **csad_resid⁻**（负方向，机制与 log_mv⁻/amt20⁻ 的逆序秩同型）：

```
score(i, m) = 在役分数(i, m) + w · rank⁻(csad_resid_z)(i, m)     # w ∈ {0.3, 0.5}，登记为负权
```

- 实现路径：runner 数据准备步骤新增 csad_resid_z 列（消费 §八 冻结文件），ext_specs 因子表追加一行——**引擎零改动**（沿 R-249/R-252 的 ext runner 路径；R-253 已验证「变换后列注入 + λ=0 严格惰性」的补丁链可行）。
- w=0 时分数严格不变（见 §二.5 NaN/IEEE 条款），G0 对拍门（§五）。
- 择时层、成本口径（ADV20 平方根冲击，逐股计价）、e1f10dz 守卫、引擎合格池**全部与在役同参**，不设独立成本模型、不豁免换手。

## 五、判胜门槛（预登记，不可事后改）

参照系（在役 a13_rsraw_e1f10dz，R-252 于 2026-08-21 复算并已对拍 full_metrics.json）：**W-full 2006-01-04→2026-08-14 ann 22.39% / MDD −33.55%**（2015 段）；W-holdout 2024-07-01→2026-08-14 ann 25.74% / MDD −16.13%。窗口口径沿库惯例（R-222/R-233）：locked = 2006-01~2024-06，holdout = 2024-07 起。

四道门（**M1.1/M1.2 须各自全部通过 G0–G2 才算过门点；G3 为披露+红旗门**）：

- **G0 对拍门（前置，非判胜项）**：**同数据实现层对拍**——同数据快照同截断下，无注入原配置跑 vs 带 csad_resid 列 w=0 跑，唯一差异 = 新因子列注入路径，须 **max|Δnav| < 1e-12**。这是 R-253 的改良设计：对旧在役产物逐位一致已被证明结构性不可能（qfq 前复权重写微漂移 ≤1.4e-07 + 末日端点伪影），故血统锚降级为警报级检查——g0_orig 的 4dp 指标若与 full_metrics.json（22.39%/−33.55%）差 >0.1pp，暂停判读并复查数据谱系。G0 失败 = 实现缺陷，修复重跑，不计 n_trials 但须披露。
- **G1 主门（选股层新信息门，收益主导）**：W-full 年化 **≥ 22.09%**（在役 22.39% − 0.3pp）**且** W-full MDD **≥ −34.55%**（恶化 ≤1.0pp）。
- **G2 增量门（机制归因）**：locked 窗（2006-01~2024-06）**复合 IC 的 ICIR 增量为正**：ICIR(五因子复合, w=试验权重) − ICIR(四因子复合) > 0。复合分数 = 引擎排序实际使用的加权秩分数（pct-rank 口径，csad_resid 逆序），IC = 逐月 spearman(复合分数, 次月收益)，池 = 引擎合格池，MIN_OBS=20。ΔIC 均值作副指标同表披露（不设门）。
- **G3 holdout 红旗门（披露，不自动否决）**：holdout 段五因子复合 IC 的 |ICIR| 若 **< 0.5 × 全样本 |ICIR|**（腰斩以上），触发红旗条款：如实写入报告并**用户知情确认后**才允许进入评分制流程。同时披露 holdout 段 NAV 指标 vs 在役 holdout（25.74%/−16.13%）作背景。

**门槛数字论证**：

1. **G1 容忍带 −0.3pp 的理由**：本因子是进攻性（新信息）候选而非防御组件，收益门必须主导——R-252 防御性组件的损耗容忍是 W-crowd −1.5pp（以 MDD 改善换收益），本实验**没有任何防御性主张**，MDD 门只是守门（见下），收益不许实质受损。容忍带不为 0 的原因：全窗聚合了 17 个强信息年（R-260 五段前四段残差 ICIR −1.02/−0.75/−0.57/−0.51）与约 4 个衰减年（尾段 −0.269），若机制真实但近段衰减，全窗年化可能被近段换手成本稀释到略负——−0.3pp 恰好容纳「前段增益 ≈ 近段稀释」的情形，但不容纳净破坏。换手成本量级参照：R-252 理论推算无信号纯漂移的年化损耗期望 −1~2pp，本因子若残差信息为零，w=0.3~0.5 的重排损耗大概率击穿 −0.3pp 门——**该门同时是「信号无价值」的筛除器**。
2. **G1 MDD 容忍 1.0pp（而非 R-233 血统线 2pp）的理由**：血统线 2pp 是为「以收益换防御」的结构改动设的；本实验无防御主张，MDD 门只是防意外（如 csad 与尺寸/流动性共振导致危机段风格漂移）。选股层加性因子在 w≤0.5、份额 ≤31% 下对组合回撤结构的影响应是二阶的（MDD 由择时层与 2015 段系统性下跌主导）；若 MDD 移动 >1pp，说明发生了非预期的风格倾斜，值得停下审查而非接受。1pp ≈ 在役 MDD 量级的 3%，是「二阶影响」的合理上界。
3. **G2 用 ICIR 增量而非 IC 均值**：ICIR 是噪声调整后的信息率，与排序因子的实际效用更同构；IC 均值增量容易被 IC 波动放大/掩盖。门槛设「>0」而非具体幅度：算术上，向 ‖w‖=1.606 的四因子复合注入 19~31% 权重份额、ICIR −0.601 且与在役四因子截面秩相关全部 |ρ|<0.6（R-257 §三.4：amt20 0.27 / pb_inv −0.18 / log_mv −0.10 / roe −0.04）的正交信息源，若信息真实则复合 ICIR 几乎必然改善；locked 窗覆盖前四强段，是因子最强证据区。G2 的实际职能是**归因守卫**：若 NAV 过 G1 而排序质量无增量，增益只能来自运气或路径效应，不应放行。预期它会过（这是诚实披露，不是降低其必要性）。
4. **G3 腰斩线的理由与预期**：R-260 已知尾段（2022-04~2026-06）单因子残差 ICIR −0.269，恰为全样本 0.601 的 45%——**红旗大概率触发，这是设计使然**（把已知衰减风险显性化为用户知情点，而非隐藏在报告附注）。复合口径下其他四因子不衰减，腰斩线未必触发；触发时用户拿到的事实是「近 26 月该因子增量贡献趋零」，据此决定是否值得占一次评分制流程。
5. **诚实先验（沿 R-254 教训）**：T4 先例——E2 四门全过、评分 0.8584 仍居 rank2 落后在役 0.8781（差 0.0197）——证明**防御性/弱改进候选在评分制 v1.1（oos_calmar/oos_sharpe 主导分量、近期窗权重高）下难胜在役**。csad_resid 若近段衰减持续，即使 E2 过门，评分阶段将直面同一逆风（OOS 分量集中在因子最弱年份）。因此本预注册把 E2 定位为「增量存在性的干净检验」，过门 ≠ 激活预期；全败则是合法且高价值的负结果（干净关闭因子线）。

**胜出选择规则**（M1.1/M1.2 同时过门时）：取 W-full 年化最高者；平局取 w 较小者（干预更少、换手更低）；再平局取 W-full MDD 较优者。E2 胜出仅获得评分制 v1.1 流程（rank1 + 无 stat_warn + holdout PASS 三条件 + 用户最终确认，R-225/R-245）资格，不构成激活。
