## 一、背景与目标（预注册 → 照单执行）

本实验严格沿 R-252《拥挤度选股降权E2预注册》§十执行清单照单执行，零改动门槛、零新增回测、零引擎/registry/paper_engine/HP crontab 改动。目标：检验「拥挤度高状态期对选股层尺寸因子做连续降权（m(t)·z_logmv）」在引擎级是否：
1. G0：λ_c=0 时实现层零回归（调制注入严格惰性）；
2. 四门（预登记门槛，一字不改）全部通过；
3. 选出唯一胜者，或全败关停方向三。

网格（n_trials=4，与台账一致）：T1=F1×λ0.5 / T2=F1×λ1.0 / T3=F2×λ0.5 / T4=F2×λ1.0。F1=阶跃 1[p>60]，F2=线性 clip((p-40)/20,0,1)；p=roll3y(756d,min250)分位（月频 PIT，调仓用上月已锁值）。在役配置 C4（sort=ext/ranksum/log_mv/amt20/pb_inv0.7/roe0.3，e1_lambda=1.0，e1_deadzone=0.30）逐参复刻。

## 二、方法与数据来源

- **runner 补丁链**：scripts/r252_run.py 基于 a9_common.patch_engine，`inspect.getsource` 取原 run_backtest 源码，在变换后尺寸因子列 `_con` 处追加 R252 调制块（OLD_R/NEW_R 锚，24 空格缩进），exec 后注入 `_R252` 命名空间；引擎文件零改动。调制作用在变换后列（原始值乘正常数不改 pct-rank 无效），λ_c=0 时乘 1.0 逐位不变（IEEE x*1.0==x）→ G0 结构可保证。
- **窗口截断纪律（阶段A）**：所有窗口指标终点统一截 **2026-08-13**（双方最后真实 mark 公共日），排除在役旧产物末日冻结行（nav=08-13 直写、num_held=0、无真实 P&L）伪影；基准 = r252_g0_orig（同数据同截断）。
- **窗口口径**：W-full 2006-01-04→2026-08-13；W-crowd 2020-01→2026-08-13；W-crisis 2023-09-01→2024-02-29；W-holdout 2024-07-01→2026-08-13。指标公式逐位复刻 a9_common.compute_metrics（ann=(1+总收益)^(1/years365.25)-1；MDD=nav/cummax-1 最小值；sharpe=日收益 mean/std×√252）。
- **台账**：experiment-ledger.jsonl 已有 IT-R252-01..04 四条（run_id 前缀 bt_r252_*_20260821，data_snapshot.kline_as_of=2026-08-14）；G0 不入台账（避免 n_trials 混淆）。冻结状态序列 roll3y_states.csv + md5=ab4143123fefccc29a21ad6160577f16，双锚通过（2023-09=92.848 / 2026-07=3.3113）。

## 四、G0 三跑事故全量披露（§七.4 执行事故）

1. **首跑 FAIL——index mismatch（n_new=5012 vs n_ref=5008）**：根因=**市场数据漂移**，非实现缺陷。在役旧产物 kline 截至 2026-08-14，本次加载数据已含 08-17/18/19/20 四个新增交易日 → NAV 多 4 行。修复：FULL_RANGE 终点 2026-08-31→2026-08-14（=预注册参照系窗口终点，不改变预登记数字）；删除 r252_g0_lam0_* 旧产物后重启。事故时点台账 IT-R252 条目 0 条，无污染。
2. **二跑仍败——max|Δnav|=0.2567**：行数对齐 5008 后逐日定位：2008-05-21 起微漂移 7.2e-09 缓慢累积到 08-12 的 1.38e-07（无跳变、无仓位翻转）→ **qfq 前复权重写特征**（2026-08-19 collect_qfq_baostock.py 变更）；末日 08-14 单日跳 0.2567 → **端点伪影**（在役产物 08-14 为行为数据末端冻结行，nav=08-13 直写、num_held=0、无真实 P&L）。结论：**「与旧在役产物逐位一致」在当前数据上结构性不可能**（旧产物底层数据已不存在），非实现缺陷。
3. **最终修复（三跑，424.4s PASS）**：
   1. G0 改为**同数据实现层对拍**：r252_g0_orig（原 a9 补丁无注入，在役配置，同数据同截断）vs r252_g0_lam0（R252 注入 λ_c=0）——唯一差异=调制注入，须逐位一致（<1e-12）→ 直接检验 G0 设计目的；
   2. **窗口指标统一截断 2026-08-13**（双方最后真实 mark 公共日；否则候选在 08-14 的真实 mark 不对称抬高 holdout ann ~0.19pp）；参照系 4dp 复算验证不变 → 预登记门槛继续有效；
   3. 数据漂移量化披露：08-13 前 ≤1.4e-07，对 4dp 指标无影响；vs 旧在役产物 max=2.567e-01（末日伪影占绝大头）。

## 五、风险与局限

- **数据漂移**：qfq 重写使新数据价格路径与旧在役产物有 ≤1.4e-07 的微漂移（08-13 前），对 4dp 指标无影响；已通过「同数据同截断对拍」隔离。
- **末日伪影**：窗口统一截 2026-08-13 排除，参照系 4dp 复算验证门槛继续有效。
- **G1 敏感性**：T2/T4 危机窗 MDD -8.12%/-8.11% 距门槛 -8.57% 仅约 0.45pp 缓冲；降权幅度（λ_c=1.0）是唯一有效档位，λ_c=0.5 两档均 FAIL → 对参数敏感。
- **胜者判定边际**：T2 vs T4 危机窗 MDD 改善差仅 0.004pp，T4 依 F2 优先规则胜出；若只看危机窗数字几乎打平，但 λ_c 相等下 F2 线性形态为既定优先级。
- **换手与容量**：胜者换手 +0.64pp，高状态月 20% 持仓轮换，未超容忍；小市值持仓集中风险未在本实验覆盖（R-252 已声明非本实验范围）。
- **资格≠激活**：T4 仅获得评分制 v1.1 资格；是否激活、如何接入 registry 属后续独立决策，本实验未做任何激活动作。
