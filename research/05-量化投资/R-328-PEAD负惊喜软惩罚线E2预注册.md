## 一、因子定义、负惊喜判定与软惩罚公式（冻结）

| 项 | 冻结定义 |
|---|---|
| SUE | yjbb 86 期 TTM+Foster 型标准意外（sue_std/sue_pct），复用 `work/r274/events_sue.parquet` 缓存（257,055 条事件 / 6,499 只），E2 执行不得重采样、不得改定义 |
| 负 surprise 判定 | PEN(t,i) = 1{sue_std < 0 且 stale ≤ 2 月}；stale = 当前月距该股最新可得报告期的月数 |
| 取号 | G = −PEN（负惊喜组预期次月收益更低 → G 与收益正相关为方向正确）；注意 C1 原始强度仅 +0.0037/t 0.88（见 §七，远弱） |
| 残差化 | G 截面去极值 1%/99% + zscore 后，对在役四因子（log_mv / amt20 / pb_inv / roe）做含截距 OLS 回归取残差 G_resid（截面 cross ≥100 才算），即 R-324 的 C2 口径 |
| 软惩罚叠加（V1 主形态） | 合成打分 s(t) = z(基准打分) + λ·z(G_resid)，λ ∈ (0, λ_max]，λ_max 冻结 **0.30**；V1 主试验 λ=0.15 |
| 明确禁止 | 单腿独立建仓、单独承诺超额收益——C3 价差两口径皆不显著（§七），R-269 归档教训（达线必须 IC 门+spread 门双查）随线携带 |

冻结理由：残差化的意义是软惩罚只捕藏在役四因子之外的「净增量」。该净增量的跨数据源稳定性已由 R-324 三重敏感性背书（mixed +0.0266/t4.35、strict only-real +0.0249/t3.85、共同月限窗 +0.0174/t3.82 全正且 t≥3.8；逐月 IC 序列 corr(新, 锚)=0.977、同号率 92.1%）。若未来在役四因子集合扩容，残差含义改变，届时必须新预注册。

## 二、PIT 对齐细则（前视风险声明）

1. 披露日源：东财 F10 主要指标 API（`datacenter.eastmoney.com/securities/api/data/v1/get`，reportName=`RPT_F10_FINANCE_MAINFINADATA`，SECUCODE 单股全历史返回 REPORT_DATE+NOTICE_DATE）；R-324 采集覆盖 5,145 股 OK / 0 empty / 0 fail。
2. 可得性判定：t 月月末评估时点，某报告期因子仅在 NOTICE_DATE ≤ 月末 且 lag = NOTICE_DATE − REPORT_DATE 落入 §三清洗带时方可进入面板；面板构造 monthly_asof（同 code 同月取最新报告期，之后按月 ffill）。
3. **严禁报告期直 join**：REPORT_DATE 是会计期末，不是信息可得日。直接以 REPORT_DATE join 行情会引入"尚未披露"的信息，构成典型前视。实证反例（R-324 §2.1）：000001 年报 REPORT_DATE=2024-12-31 → EM NOTICE_DATE=2025-03-15（真始披露日，lag≈74 天合法域内）；而 yjbb 回填库同记录「最新公告日期」=2026-03-21，滞后 371 天——回填型公告字段同样不可直用，必须走 §三清洗带+§四回退。
4. 收益端同口径 PIT：IC 计算用 r_{m→m+1} 月度不重叠窗口（spearman(F_m, R_{m→m+1})），无窗口重叠前视。

## 三、清洗规则冻结（先于一切 E2 计算，禁事后调参）

- lag = NOTICE_DATE − REPORT_DATE（自然日）；**0 ≤ lag ≤ 180 天记为真实披露日可用**；缺失 / 负值 / >180 天 → 走 §四回退路径并计入替代率。
- 上限依据（引证 R-324）：季报法定披露上限 30 天（Q1）/62 天（H1）/31 天（Q3）、年报 120 天，180 天留余量；yjbb 型 ≈次年同期回填特征必被捕获。
- 冻结统计基线（R-324 实测；E2 执行期如数据更新，须重报分布对照本表后才可开工）：
  - real_cover = **81.7%**（210,001 条真实披露日 / 257,055 条事件）
  - fallback_missing = 30,739（12.0%）、fallback_anom = 16,315（6.3%），其中 **>365 天桶 16,264 条**（p95 lag = 393 天）
  - 直方分布：0–30 天 100,928 ｜ 31–62 天 58,487 ｜ 63–90 天 14,604 ｜ 91–120 天 35,005 ｜ 121–150 天 922 ｜ 151–180 天 55 ｜ 181–365 天 51 ｜ neg=0
  - 分报告期替代率均匀（17.3%~19.1%，无单期集中）；清洁部分分年度滞后 p50 合法域内（2008–2026 季报均 ≈30d、H1≈56d、FY≈109d）
  - 分布证据存档：`work/r324/disclosure_dist.json`（EM 源 PIT 审计留存，对应 R-324 立项前置条件②）

## 四、回退规则（真披露日缺失时的降级路径）

1. NOTICE_DATE 缺失 / lag<0 / lag>180 天 → **唯一冻结降级路径：回退法定期限上界代理**（R-274 口径：Q1→当年 4/30、H1→8/31、Q3→10/31、年报→次年 4/30），并计入替代率。
2. >365 天异常桶（000001 滞后 371 天型 yjbb 回填特征）正是第 1 条覆盖对象：代理日取 REPORT_DATE 后的期限上界，方向保守不前视——宁可晚知道，不能早知道。
3. 口径纪律：混合面板（真实日+回退代理）为主口径；strict 仅真实日（fallback 事件整体剔除）为强制敏感性对照。两口径结论方向背离或显著性跌破 t≥2 → 按 T2 终止开关处理（§六），如实归档。

冻结理由：18.3% 替代率意味约五分之一事件的"新鲜度分级"非精确，只能靠保守代理方向 + 双口径强制对拍控制风险，不允许执行期自行改带（例如放宽到 240 天）救样本。

## 七、弱项如实记录（R-324 自披露全文携带，禁美化）

1. **C1 原始强度门未过**：G=−PEN 原始 IC +0.0037 / ICIR 0.062 / t 0.88（n=200）；锚版 −0.0073→G 口径 t +1.07——两口径皆大幅低于 0.25 强度参考线。敏感变体 pen_sig_negpart −0.0084/t−1.34、pen_std1 −0.0071/t−1.98 更弱。**本线唯一成立的形式只有残差化净增量（C2），原始惩罚信号本身单薄。**
2. **C3 价差门未过**（对标 R-269 spread 门 Q5−Q1 t≥2）：−0.061pp / t −0.47 / 负月占比 52.2%（n=157）；strict 口径 −0.025pp/t−0.21；锚版 −0.118pp/t−0.79/52.6%。双口径皆 |t|<1，无交易可行性证据。处置：不做独立腿；等价风控论证＝正交分量小权重叠加进在役组合，增量风险由 λ_max=0.30 上界 + G4/G5 门约束；分组单调性作披露项替代价差承诺。
3. **新鲜窗自洽异常**：sue_std ≤2 月窗 IC 仅 +0.002 / t 0.24（n=167），低于 R-251 真实口径参考 0.0266 与本链路代理版 0.0151。归因（不完全定论）：R-251 参考值来自同花顺 ths_ttm_panel（1997 起、avail 或含快报/预告刷新），与本链路 EM NOTICE_DATE 数据库惯例不同；全样本自洽吻合而窗口类指标敏感。→ 已映射为 T1 终止开关监控项。
4. **18.3% 替代率敞口**：missing 12.0% + 异常 6.3%；期限上界代理保守不前视，但部分事件的"新鲜度分级"非精确，残差增量可能因此被低估（保守方向误差）。
5. **线索性质定性不变**（沿 R-274/R-324）：组合内正交分量，非独立 alpha。任何把 C2 解读成"发现新 alpha 因子"的表述都违反本预注册。
