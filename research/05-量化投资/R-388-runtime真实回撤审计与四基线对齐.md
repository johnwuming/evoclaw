## §1 背景与目标

当前存在四个来源不同、从未同表对齐的组合数字：①看板展示口径（静态 58/42 月度，ann 14.44%/MDD −9.69%，R-380）；②滚动等波动对照（−5.71%，R-381）；③两腿全窗回测参考值（−16.64%，R-372，仅披露）；④runtime 实际在跑组合（8 股约 60% + 现金 40%，R-378 核验、用户 08-31 12:55 评审确认）从未被直算过回撤。

## §2 方法与数据来源

**关键同源发现（本审计的成立前提）**：`nav_curves.csv` 的 A 列与 `a13_rsraw_e1f10dz_full_nav.csv`（runtime 在跑引擎的回测净值，与 paper-state.json 的 model_version 完全一致）在月频上呈**恒定比例 0.15184**（2013-08/2015-08/2020-08/2026-07 四点核验全部一致）。即展示口径的微盘腿与 runtime 在跑的引擎是**同一条净值序列**，仅缩放基期不同。因此展示 58/42 与 runtime 60/40 的对比可以做到**同窗、同腿**，差异只来自两处：第二腿（gold vs 现金 0）与 A 腿权重（58.03% vs 60%）。

**计算引擎**：逐行复用 task-0591 已验收引擎（R-380 语义），锚点先复现再算新变体。runtime 直算口径：
- 组合 = wA × A 腿月收益 + (1−wA) × 现金（**现金腿收益按 0 处理**，如实披露；paper 引擎现金 40393 自 08-14 创建未变、不计息，与该处理一致）；
- 成本仅按权益腿换手 0.13%×|ΔwA| 计（现金↔权益转换无市场交易成本，比展示口径双腿计成本更宽松，对 runtime 有利）；
- 主口径 wA=0.60（08-28 市值口径精确值），敏感性 wA=0.59607（创建时成本基础 59567/100000）与 0.606（评审引用值）；
- 权重处理为**月度再平衡至静态 60/40**（与展示口径机制对齐）；另算买入持有漂移变体；实际 runtime 权重由 a13 择时层动态决定并漂移，静态 60/40 是为同表可比的简化，非实盘机制；
- 日频直算：a13 引擎日频净值，0.60/0.40 月末再平衡（2013-07-31 归一起算，首月含 2013-08 完整收益，与月频口径对齐）。

锚点复现全部 PASS：静态 58/42 → 14.4394%/−9.6896%（=R-377 重算A）；滚动 6m → 10.1173%/−5.7067%（=R-379 对照列）；日频 A 腿 MDD −33.5542% = 引擎 metrics.json 的 max_drawdown −0.3355 逐位一致。计算脚本与全部中间数：`work/task-0602-compute.py`、`work/task-0602-results.json`。

### 3.2 直接回答：展示 −9.7% 与 runtime 真实的差距

**同窗同腿同月频的严格对比（④b vs ①）：runtime MDD −10.34%，比展示 −9.69% 深 0.65pp；年化低 3.11pp（11.33% vs 14.44%）；Sharpe 低 0.285（1.114 vs 1.399）。展示口径在收益与风险调整后全面更乐观，用户疑虑方向成立。**

差距的结构性原因只有一个：展示口径的 42% 是 gold 腿（自身有正收益、回撤段有微弱缓冲），runtime 的 40% 是零收益现金；叠加 A 腿权重高出 2pp。同一 A 腿、同一场 2015 股灾（④ 最深段与①完全同段：2015-04→2015-07），现金腿接不住而 gold 腿至少不跌。

**口径诚实披露（重要）**：上表 0.65pp 是「月频对月频」的可比答案。若按日频真实路径（④d），runtime 组合历史 MDD 达 **−21.31%**（2015-06-12→07-08 月内崩盘，2019-09 才修复）——月末采样会系统性低估月内深回撤。展示口径因 gold 腿本地无日频序列（shadow_nav 仅月频 n=157）**无法做日频对日频换算**，此为数据缺口，不做猜测。严谨表述：0.65pp 是同口径下界的差距；真实日频差距大概率更大，方向仍是「展示更乐观」。

**runtime 实仓本身**：08-14 起跑仅 2 周（11 个收益日），实际窗口 MDD −2.55%、累计 +1.03%，无统计意义；本审计长窗数字是「runtime 权重 × 在跑引擎历史净值」的模拟直算，非实盘纪录，且 8 股实际持仓与引擎回测的 20 只等权配置存在粒度差（引擎回测为策略上限口径）。

## §4 结论与建议

1. **疑虑证实**：展示口径（−9.69%/14.44%/1.399）相对真实在跑的 60% 微盘+40% 现金组合，回撤浅 0.65pp、年化虚高 3.11pp、Sharpe 虚高 0.285。虚高主因是「42% gold 腿」在 runtime 中对应物是零收益现金——这与 R-378「设计组合 ≠ 运行组合」的结论在同一数据上再次闭合。
2. **决策引用建议**：明早决策若需引用 runtime 组合的风险数字，建议用 ④b（−10.34%/11.33%/1.114，与展示同窗可比）作主数字；对风险敏感的场合同时披露 ④d（日频 −21.31%）。③（−16.64%）是含 2013-15 高收益段的披露参考，①② 均为设计层通道，都不是 runtime。
3. **数据缺口与最小补数方案**（如需彻底闭合）：gold 腿日频净值序列缺失，导致「日频对日频」的展示口径无法直算；最小补数 = 从 gold 引擎侧导出日频 net 路径落盘（一条 CSV），即可把四基线全部升到日频同口径。本次未自行补数，遵守只读约束。
4. **看板改进建议**（不改动，仅建议）：四基线数字建议在看板同表披露并标注「窗口/口径/是否 runtime」三要素，避免再次出现跨口径误读。
