## 一、背景与目标

层2 现有两条收益流：a13（A股微盘质量组合）与 gold（金价趋势引擎）。R-292 中央控制层已按三腿 ERC 预留第三腿接口（corr 上限 0.85，近重复对触发等波动封顶规则②），缺一条驱动源异质的第三分散腿。R-331 E1 画像三链证据全部过线（净值史足够、风险特性温和、独立性大幅低于 R-255 门槛 0.5、容量零约束），判定「值得 E2」，并遗留两个口子由本预注册冻结：

1. **G1 判门口径**：单资产时序策略无横截面 IC，需按资产特性另行预注册（R-331 §四建议方向：超额 vs 货基设定阈值 + MDD/Calmar 相对提升 + 组合层为准绳）；
2. **主形态与期限档取舍**：R-331 建议主形态锁 px>SMA200 × 货基现金增强，期限档优先 511010+511260，511090 因 n=38 过短只列辅助观察臂。

**待检验假设（冻结，一句版）**：国债ETF px>SMA200 × 货基现金增强作为层2 第三腿，能在成本后保持对货基的正超额与不劣于买入持有的风险调整效率，并通过负相关稀释实际压降两腿组合（a13+gold）的 MDD。

### 2.2 信号定义与执行规则（冻结，沿 R-303 冻结族，PIT 安全）

| 项 | 冻结定义 |
|---|---|
| 方向腿 | px > SMA200（200 交易日日频收盘均线），月末取样布尔 → 下月全仓/空仓 |
| 现金增强 | 空仓部分持货基：r = w×bond + (1−w)×mmf |
| 合成仓位 | w(t+1) ∈ {0,1}，月频重算、月频调仓；信号不可得期（上市初均线未满 200 日）w=0 全现金 |

| 波动目标臂 | **不作 E2 试验变体**：R-331 已证退化（债券实现波远低于目标 10%，权重恒近满仓，511010 波动目标臂年化 2.80% ≈ 买入持有），仅作口径声明保留，节省 trial 预算，如实声明 |
| 成本口径 | **引证现行成本 v2 冻结口径原样沿用，不改**：单边佣金 0.10% + ETF 价差 0.03% = 每次变仓 \|Δw\|×0.13%（R-304 预注册冻结，R-333 确认为现行回测成本假设 v2，R-314/R-316 已外推沿用）；毛口径=现金增强零成本，净口径=毛−成本。R-333 可实现中间态 11.5bp/边仅作影子期对账参照，不入判门 |

### 2.3 数据源已知缺陷（披露项，R-331 清单照抄携带，E2 报告必须逐条回应）

1. **东财封锁** → 官方成交额字段缺失，amount ≈ vol(手)×100×不复权收盘价，**估算口径非官方值**，容量门据此打折判断；
2. **IOPV/溢价历史序列缺失** → 折溢价摩擦未量化；E2 执行期需补实时溢价率快照入哨兵，影子期将折溢价成本并入对账；
3. **腾讯序列坏点插补清单**：511010 四个窗口、511260 上市首日（2017-08-24 极值打印）、511090 无；插补方法 = 相邻两日收盘几何均值；新浪侧 |ret|>cap 异常 0 个；坏点日期全清单见 `work/task-0509-notes.md`；
4. 511010 头三周（约 2013-03-05 上市初）两源均缺；511090 缺 2023-03-08~06-12 段；
5. 两源水平系统性小差且越近今越收敛（新浪侧普遍高 0.1~1%，疑一方含平滑/复权处理）→ 新浪只作方向性核验；
6. 数据源单一依赖腾讯 hfq（东财封锁）→ 终止开关 T1 跳点哨兵（见 §五）。

## 四、结论与建议

1. 本预注册已将 R-331 遗留的 G1 判门口径正式冻结（§3.3 G1 双过制 + G0–G7 全门 + T0–T4 终止开关），登记后 E2 执行只得按表取数判读，无自由裁量空间。
2. 形态结论沿 R-331 建议：主形态 V1=511010 px>SMA200×货基现金增强；波动目标臂因 R-331 已证退化而不入试验网格（声明性冻结）；511090 冻结为辅助观察臂受 T4 约束。
3. 判门设计取向如实声明：本赛道候选的价值主张不是绝对收益（天花板 3~5%），而是「低收益换负相关与回撤互补」——因此主判据为 G1 双过制（超额+风险调整不劣化）+ G3 组合层门（三腿必须实际压降两腿 MDD），G3 才是假设的直接检验。
4. 弱项如实入档（R-331 §四.4 全文携带）：①绝对收益低，ERC 解析会被自然降权（预期行为，非失败）；②5年/10年档 MDD 未被信号改善，压降组合 MDD 依赖负相关稀释；③折溢价摩擦未量化（IOPV 缺失），影子期对账补课；④数据源单一依赖腾讯 hfq，T1 哨兵前置；⑤货基腿场外申赎 T+0/T+1 摩擦未计（量级 <0.05pp/年，沿 R-304 披露口径）。
