## 一、关闭依据链

### 1.1 判定来源（R-261 §一，task-0423）

- 判定标准（任务书预登记）：**最优形态 0.2% 单边成本点净超额 ≥ +0.5pp 才值得重写预注册**。
- 实测：五变体（V0 原始 / V1 三月平滑 / V2 缓冲带 / V3 季度 / V4 组合）0.2% 点净几何超额全负：V0 −0.90 / V1 −0.32 / V2 −2.14 / V3 −2.44 / V4 −1.14（pp/年）。
- 最优 V1（3 月均值平滑，月均换手 τ=0.41）为 **−0.32pp，距门 0.82pp**。
- 曲线形状：净超额@0.2% 对 τ 呈**倒 U 型**，内点峰值在 V1 但峰值为负——低换手端信号陈旧化摧毁 alpha，高换手端成本吞噬；**网格内不存在能过门的成本-换手组合**（过门需「V0 级毛超额 ≥2.5pp + V1 级换手 τ≤0.49」，权衡前沿上无此点）。
- 结论（R-261 §一.2 原文）：「五个变体全部不过门 → 建议关闭引擎 B 行业轮动线」。

### 1.2 停止规则引用（R-258 §六原文，照登不改）

> 1. **G1 任一子条件失败 → 引擎 B 行业轮动线关闭**：不进影子、不做引擎级重试、不进 E3。
> 2. **成本敏感性显示 c=0.1% 单边净几何超额 < 0 → 同样关闭**（连最便宜的 ETF 实现都亏损，信号无实现价值）。
> 3. **禁止复活路径**：换 k、改 Top-N、加缓冲持有规则（如"跌出 Top10 才卖"）、改成本口径、扩网格、改分段/窗口——任何此类尝试 = 新预注册 + 报告明示 post-hoc + 台账独立计块 + 默认不采信。降换手形态若要研究，只能以新预注册重启，不继承本线任何资格。
