# R-357 模型说明卡版本化绑定（task-0558，2026-08-29）

## 背景与问题
task-0557 在版本页落地模型组成说明卡后，用户（2026-08-29 14:01）指出其策略文案与旧版同类问题：四行描述（"A股因子选股"等）为静态内联字面量，vC-1 迭代换引擎后文案不会跟随，会为新引擎显示旧引擎的错误描述。

## 方案
前端文案与引擎解耦，按 ID 键控（`src/engineCopy.js`，纯 JS 零依赖）：

| 键 | 文案 |
|---|---|
| `a13_rsraw_e1f10dz` | A股因子选股（月频调仓） |
| `gold_trend_sma200` | 黄金ETF 200日均线趋势择时 |
| `ddc` | DDC 回撤控制（≤-20% 降仓×0.5，回补 -5%，T+1 生效） |
| `solver_equal_vol_v1` | 等波动率求解器（两腿风险贡献相等） |
| 未注册 | `<engine_id>（说明待补）`；空 id → `—` |

- `buildModelRows(detail)` 纯函数：文案一律经 map 键控解析，数值（registry/权重/SMA/DDC 参数/窗口）仍从详情 schema 动态渲染；ModelCard 只负责渲染。
- **关键实现细节（真实数据驱动）**：实测 vC-0 详情发现 equity 的 component_ref 为 registry_ref 型——`engine_id:'A'` 只是类 ID，具体引擎在 `registry_entry:'a13_rsraw_e1f10dz'`。故 resolver 先查 engine_id、未命中再查 registry_entry（任务书允许双键控），两处均未注册才降级，保证 vC-1 换引擎后：已知新引擎显示新文案，未知新引擎显示「待补」而绝非旧文案。
