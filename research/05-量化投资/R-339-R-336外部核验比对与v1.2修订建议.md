### 2.2 建议吸收（4 条）

**A1（源 E3，外部 §6.1）portfolio_version schema 扩充**
- 改法：§1.2⑤ 字段清单中，sleeves{} 每条指针附 `code_hash + data_cut`（model manifest 最小集）；新增 `capital_policy{gross_limit, net_limit}`；`solver_ref` 扩为 `solver_id + params + tolerances + fallback`。

- 边界：constraints（bounds/turnover/sector）按 §1.2④ 既定口径留 P2 演进，不进 v1.2。

**A2（源 E4，外部 §4）构建层可交易性过滤 + 后验检查两步显式化**
- 改法：§1.2④ 职责段加两句——①权重求解前先过 Data Layer `tradable_mask` 过滤候选；②weight_solution 输出前做后验检查（权重取整、最小交易单位、现金残留）。
- 落点：§1.2④；Phase B 落地。数据侧 Mask-First 已备（R-333 实证），只缺构建层显式步骤。

**A3（源 E5，外部 §4/§5）协方差估计方法对比留档**
- 改法：Phase B 校准期将 Ledoit-Wolf 与样本协方差、EWMA 各算一遍并留档对比（2-3 腿成本≈0），结论作为 `solver_meta.cov_estimator` 选型依据记录。
- 落点：§8 Phase B 动作 5 后追加一行（或 §1.2④ 注）。不建服务、不换默认，只消除「单一方法永久锁定」隐患。

**A4（源 E2/E14/E15/E21/E28 残余）字段与细则包**
- 改法四小项：①`weight_solution.solver_meta` 增收敛状态/随机种子/诊断字段（§1.2④ 输出契约）；②`weight.solved` 事件 payload 约定含触发原因（定时/RC 偏离/兜底）（§3.2）；③`promotion.executed` payload 引用 data_cut 或市场快照标识（§3.2）；④§1.2⑥ canary 档补一句「启用时须先定义期限与失效自动降级条件」。
- 落点：均为 payload 约定/一句话条款，Phase A gate spec 与 Phase B schema 定稿时顺手落。
