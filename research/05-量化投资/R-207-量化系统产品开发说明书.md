# 第一部分 产品概述

## 1.1 产品定位

个人量化投资系统的**研究-验证-模拟-进化一体化平台**。核心用户故事：

> **无名只在三个时刻出现**：① 产生想法（一句话）② 收到通知（微信摘要）③ 做出决策（页面点确认/放弃/回退）。其余全部自动。

## 1.2 系统五层流程（业务架构）

```
L0 数据层     K线/财务/指数/估值采集 → 校验 → 快照
L1 因子层     因子注册表 + IC台账 + 相关性治理 + 月度体检
L2 选股层     股息+ROE+ROA小盘策略（当前 V2_d25_n30_p10）
L3 择时层     trendvol × PE估值信号（当前 i4_q3z，系数0~1）
L4 模拟盘     paper_engine 日度/调仓/校验 cron 全自动
L5 进化闭环   想法池+LLM因子进化 → 门禁 → pending → 人工确认 → 生效
```

# 第三部分 后端逻辑

## 3.1 版本对象 Registry（核心，R-206 v4 定稿）

**一个版本 = 五维冻结组合**：选股参数 × 择时配置 × 因子集 × 数据快照hash × 代码引用。存 `model/registry/vX.Y.json`，schema：

```json
{
  "version_id": "v1.2",
  "status": "candidate | pending | active | sota | retired",
  "created_at": "2026-08-20 21:00",
  "selection": { "strategy": "dividend_quality_smallcap", "params": { "div_min": 0.025, "roe_min": 0.15, "roa_min": 0.1, "price_cap": 10.0, "n_hold": 30, "sort": "mv" }, "factors": ["div_yield_ttm","roe_ttm","roa_ttm","circ_mv"] },
  "timing": { "enabled": true, "type": "i4_q3z", "params": { "ma_window": 120, "vol_window": 60, "target_vol": 0.25, "vol_floor": 0.5, "q3z_win_months": 36, "q3z_hi_sigma": 1.0, "q3z_max_cut": 0.4, "w_min": 0.3, "smooth_alpha": 0.3, "timing_rebalance_min": 0.35 } },
  "data_snapshot": { "kline_hash": "…", "financial_hash": "…", "valuation_hash": "…", "as_of": "2026-08-15" },
  "code_ref": "git commit 或 scripts tag",
  "backtest_refs": { "endtoend": "results/bt_v1.2/endtoend.csv", "baseline": "results/bt_v1.2/baseline.csv", "walkforward": "results/bt_v1.2/wf.json", "segments": "results/bt_v1.2/segments.csv", "metrics": { "annual": 0.0, "mdd": 0.0, "sharpe": 0.0 } },
  "gate": { "icir_is": null, "icir_oos": null, "max_corr": null, "dsr": null, "logic": null, "n_trial": null },
  "provenance": { "trigger": "idea#17 | cron | manual", "parent": "v1.1", "report": "iteration-20260820" }
}
```

**五个流转操作**（runner子命令，全部追加 decision-log）：

| 操作 | 命令 | 逻辑 |
|---|---|---|
| 回测 | `evolution_pipeline.py backtest --version v1.2` | 读registry展开参数→跑两腿（端到端+同口径基线，同数据快照）→产物路径+指标写回backtest_refs→试验台账+1 |
| 评估 | `evaluate --version v1.2` | 读backtest_refs过五项门禁→PASS则status=pending |
| 生效 | `activate --version v1.2` | registry内容写入main.json（paper_engine零改动）→switch_log+decision-log |
| 回退 | `rollback --to v1.1` | registry旧版重新activate→decision-log（页面触发需人工确认） |
| 临时覆盖 | `override --reason 演练 --ttl 24h` | 临时禁择时等，TTL自动过期，收敛环境变量滥用 |

**防漂移三校验**：
1. paper_engine daily 启动：main.json 内容hash ↔ registry[active] hash 比对，不一致→微信告警
2. 页面读 backtest_refs：data_snapshot ↔ 当前数据hash，数据已更新而回测未重跑→标黄「结论基于旧快照」
3. 环境变量裸用（如PAPER_TIMING_V4=0不走override）→paper_engine警告日志

**迁移兼容**：main.json 不动（模拟盘零中断）；W5 建registry时抽v1.1为首个版本对象，activate幂等校验；历史回测产物补标 data_snapshot=unknown。

## 3.2 自动化管道（统一 runner）

```
evolution_pipeline.py --cycle   （半月度 cron，周六 09:00）
  Step0  数据校验（10项健康检查）——FAIL则fail-fast：跳过本轮+微信告警（K线停更>48h即此路径）
  Step1  数据快照（算hash、注册snapshot）
  Step2  想法消化——pool中open想法→LLM结构化为「假设卡」（数据源/计算式/方向先验/经济学逻辑）
         →假设卡回写pool（status=digesting）→ 无名页面/微信点头 → 进测试队列（或自动模式跳过点头）
  Step3  因子迭代——测试队列优先；无想法时LLM进化补位（单批次试验预算N个候选，计入n_trials）
  Step4  版本化回测——backtest --version 新候选（两腿同口径）
  Step5  评估——evaluate（五项数字门禁）
  Step6  PASS→pending+影子并行启动；微信通知摘要（版本/门禁结果/WF/报告链接）
  Step7  （人工确认后）activate → 生效

monthly_factor_health.py   （每月1日 cron）
  全库相关性→层次聚类→每簇保留ICIR最高→冗余降权建议→衰减标记→体检报告→decision-log

risk_patrol.py   （每日，并入 paper daily 或独立cron）
  退出纪律指标距阈值余量→触界即动作（降仓/熔断）+告警；微盘拥挤度4指标→异常降仓建议
```

**五项数字门禁**（M2.6，对齐WorldQuant BRAIN + DSR）：
1. IS全样本 ICIR 年化≥0.5
2. OOS（WF段）ICIR 达标且不显著劣于IS
3. 与存量因子/模型最高|ρ|<0.7（超过需Sharpe显著更高破例）
4. DSR>0.95（多重检验校正，显示n_trials）
5. 一句话经济学逻辑（黑箱一票否决）

附加检验：影子统计检验（配对日度超额差t检验+Jobson-Korkie）；参数平坦性（±10~20%邻域扰动不剧烈劣化）。

# 附录A 术语表

| 术语 | 定义 |
|---|---|
| IC/ICIR | 因子值与下期收益截面相关系数 / IC均值÷IC标准差（年化=月度×√12） |
| DSR | Deflated Sharpe Ratio，多重检验校正后夏普（Bailey & López de Prado 2014） |
| n_trials | 全局试验次数（每次回测/因子测试/进化迭代+1），DSR分母 |
| Registry | 版本对象库：选股×择时×因子×数据快照×代码引用五维冻结 |
| PIT | Point-in-Time，只用当时可知的数据（披露日vs报告期） |
| WF | Walk-Forward 样本外验证 |
| 灰度阶梯 | 影子(只记账)→小资金(≤10%)→放量→全量 |
| 审计样本段 | 锁定不可用于日常迭代的数据段（2024-06后），仅季度regime体检 |
| 四层归因链 | 基准→选股基线→端到端→模拟盘，Δ₁选股/Δ₂择时/Δ₃偏差 |
