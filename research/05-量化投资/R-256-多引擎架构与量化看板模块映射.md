## 一、背景与目标

主会话 2026-08-21 13:05 与用户对齐、13:13 主 agent 修正定稿的目标架构（本报告不推翻，只做模块映射）：

- **通用 N 引擎框架，不写死双引擎**：引擎 = 可插拔的同类组件。当前实例：引擎 A = 在役 `a13_rsraw_e1f10dz`（微盘选股）；引擎 B = 全 A 板块轮动（E1 达线 R-255：k=1 行业动量 Top5 月频；待 E2 预注册→引擎级；**尚未存在**）；未来 C/D 同构接入。
- **引擎同构定义**：每个引擎 = 信号/选股逻辑 + 自带择时与回撤内化 + 独立 NAV + 独立 registry 版本线 + 影子观察通道。引擎 A 的择时内化（趋势门+ddc+q3z）即此定义的现有实例。
- **中央风控 = 独立横切层，明确不属于任何引擎**（尤其不放进 B）：战略配置器（N 引擎权重，风险贡献定比例）+ 再平衡带宽（偏离机械拉回，不追表现）+ 组合级回撤门（保险性质）。哑层、无方向观点、不做方向择时。
- **组合层 = N 引擎通用聚合**：组合净值 = Σ wᵢ×NAVᵢ，引擎数可变；不写死「A+B 合成」。
- **B 上线路径** = 双 NAV 影子观察先行（参照 a12_s2_reb 影子机制 R-248），3-6 个月影子期后再谈真金分配；影子期与分配均为用户决策点。
- 信号层合并（真复合模型）= 远期，不在本报告范围。

目标：盘点现有量化看板全部模块 → 按四层（层0 共享数据基础设施／层1 引擎层／层2 中央风控层／层3 组合与呈现层）标注归属 → 给出 删除/复用/迭代/新增 四分类判定 + 依赖关系 + 分阶段实施顺序。
