# R-332 可转债剩余余额免费数据源可行性侦察（task-0510）

## 1. 背景与目标

CB 去相关三路径穷尽后（R-289/R-293/R-295/R-298/R-299），「剩余余额中性化」是唯一未试变量。R-299 当时以「公告级数据需采购、免费源缺失」收口。本任务实测三个候选免费源，回答：**免费公开数据能否重建可转债剩余余额/转股进度的历史序列？**

## 2. 方法与数据来源

逐源实测 + 十券抽样（2017–2018 年上市老券），每源记录访问方式、字段存在性原始证据、历史深度、PIT 风险。过程证据（原文摘录、样本落盘清单）见 `shared/results/work/task-0510-notes.md`。

## 3. 核心发现（一页源清单）

| # | 源 | 访问方式 | 「剩余规模」字段 | 历史深度 | PIT 风险 |
|---|---|---|---|---|---|
| 1 | 东方财富 datacenter（RPT_BOND_CB_LIST，akshare bond_zh_cov / bond_zh_cov_info 同源） | 免登录 HTTP API | ❌ 无。仅 ACTUAL_ISSUE_SCALE 静态发行规模 + 实时行情快照（1050 只在库，含已退市券的发行元数据） | 无历史维度 | 快照不可回溯，对回填无用 |
| 2 | 集思录 cb_list_new（POST，免 cookie） | 免登录可 POST，**限 30 行**；全量需登录 cookie | ✅ curr_iss_amt 原文：`"curr_iss_amt":5.5,"year_left":5.981`，30/30 有值 | **端点无日期参数，仅当前快照，历史深度=0** | 实时快照 PIT 好，但无回填能力 |
| 3 | akshare 1.18.94 | 本机 python | 仅 bond_convert.py 转发集思录 curr_iss_amt→剩余规模；东财系函数无余额字段 | 无历史接口 | — |
| 4 | Wayback Machine 存档 | CDX API | 本机到 archive.org 不通（sanity 查询也超时空返），通道在本环境不可验证 | — | — |
| 5★ | 东财公告接口（np-anotice-stock 列表 + np-cnotice-stock 正文，免登录） | 结构化 JSON + 纯文本正文 | ✅ 季度《转股结果暨股份变动公告》含精确未转股余额。原文摘录（光大转债，2022-07-05）：「尚未转股的光大转债金额为人民币 24,198,864,000 元…占发行总量 80.6629%」 | 存续期内季频可翻取（见抽样表）；缺点是只能整页向前翻、不支持日期过滤 | ★ 公告级最高（披露日即事实日） |

十券抽样结论：8/10 通过公告通道拿到真实余额锚点（蒙电 13 份、光大 16 份完整覆盖转股期，节律≈季度）；2 只零命中系老公告沉底于深页、翻页深度不足所致，非数据不存在。退市信息与发行规模在东财全量可得（样本 10 只中 9 只已退市仍可查）。

## 4. 结论建议

**分级：部分可行。**

- 推翻 R-299 的隐含前提：「完全免费缺」不成立——季度粒度 PIT 剩余余额可以零成本重建。
- 坐实其工程判断的部分：月度粒度不可得（公告原生季频，月度只能插值）；全市场一次性建库需深翻页+正则抽取+多期转债清洗，工程量与第三方数据商定价相比未必划算。
- 缺口形态：①季频非月频；②公告检索深度（可用巨潮资讯 searchkey+日期区间解决，本次未实测）；③同名正股多期转债需按标题拆分清洗；④集思录全量当前快照依赖登录态。
- 若未来重启剩余余额中性化线：建议先做单引擎侧影实验——用季度末快照 + 前向填充构造低频中性化因子（无需采购），成本仅为一次性的爬取清洗脚本；是否立项属用户门决策，本报告不拍板。
