# R-236 大小盘轮动可行性调研报告

- 任务号：task-0365（阶段A 实证 + 阶段B 本报告）
- 日期：2026-08-18
- 结论速览：**立项（窄口径）**——RS 趋势轮动仅进入 v6a_def 持仓态内部（微盘弱势期切大盘腿）；空仓态换大盘不可行（F 变体证否）
- 试验登记：n_trials = 7（Part B 信号变体 4 + Part C 复合组合假设 3）

## 一、背景与目标

### 1.1 Calmar 不变式约束与轮动路线动机

现有微盘量化体系（v6a_def 架构：门控微盘池 + MA15 择时门 + 空仓现金防守）长期受"Calmar 不变式"约束：年化 25%+ 与 MDD ≤20% 不可兼得。R-230 五维信号扩展与 R-231/R-234 择时 v2 批次均在"何时退出微盘"维度上做文章，但退出后的资金只能闲置现金——系统性熊市（2008/2015/2018）里这已是最优解，但在**风格分化段**（2017 蓝筹年、2024-01 微盘踩踏、2026 流动性枯竭），微盘崩溃的同时大盘仍在上涨，空仓放弃了这部分收益。

轮动路线的本质是"收益源切换"：微盘弱势期切大盘腿继续持有风险资产，而非仅靠空仓防守。两者互补而非替代：

- 择时防守腿：针对系统性熊市（全市场同跌）；
- 轮动腿：针对风格分化段（micro/large 走势劈叉）。

### 1.2 调研三问（本报告回答范围）

1. 框架映射：常见大小盘轮动信号家族如何接入现有体系；
2. 数据可得性：大盘腿两种口径是否可 PIT 复现；
3. 最小实证：RS（相对强弱）趋势信号的画像与组合预览，是否支撑立项。

范围约束：不涉及期权。

## 二、方法与数据来源

### 2.1 计算环境与数据池

- 环境：VPS /opt/finworker/bin/python（pandas 3.0.5 / numpy 2.5.2 / pyarrow 25.0.1）；数据为 HP 量化主机 qfq 池只读 rsync 副本（HP 内存恢复后按先例仍留 VPS 计算）。
- 数据池：5,206 文件，5,030 个交易日（2005-12-01 ~ 2026-08-14），日均股票数 2,966.8。
- 微盘腿口径交叉验证：本任务自算 Mmicro vs E1 signal_series（R-231 产物）：n=5003，日收益相关 0.9999992，mean|Δret|=9.2e-06，final_ratio 0.9955 → **逐位同构 PASS**。

### 2.2 大盘腿构建口径（两口径均已实证可得）

- **口径A（主用）**：qfq 池每日按总市值 mcap=close×outstanding_share 排序前 20% 等权（Mlarge_top20）——与微盘腿同一 numpy lexsort 流式实现对称，零边际数据成本。注意该"大盘池"实含中盘（5400 只中前 20%≈1080 只）；qfq 池无退市股，但退市股几乎从不进前 20%，对大盘腿影响可忽略（披露项）。
- **口径B（对照）**：HP 在库 `hs300_daily_20060101_20260808.parquet`（官方指数腿）；成分股历史仅当前快照、无 PIT 历史 → 成分加权腿不可 PIT 复现，用官方指数替代作对照。

三条腿全期画像（等权日频，2006-01~2026-08）：

- Mmicro：年化 15.81% / MDD −71.45% / Calmar 0.221
- Mlarge_top20：年化 26.18% / MDD −69.17% / Calmar 0.378（前段历史大盘牛市更强）
- hs300 指数：年化 8.15% / MDD −72.3% / Calmar 0.113（2008 年 −72.7% 真实存在）

腿间日收益相关：micro↔large 0.864，large↔hs300 0.937，micro↔hs300 0.728。**micro/large 相关 0.864 是后续"空仓态换大盘不可行"结论的根因之一。**

### 2.3 RS 信号定义与四变体

信号源：RS = Mmicro / Mlarge（两腿等权净值比）。四变体为 RS 的趋势态判定：

- ma20：RS 上穿/下穿 20 日均线（过频，年均约 12 次切换，弃用）
- ma60：RS 上穿/下穿 60 日均线（主候选）
- mom60：RS 60 日动量符号
- ma5_20：RS 的 MA5/MA20 双均线交叉（副候选）

事件口径沿用 E1（R-231）方法论：episode=连续触发日段，事件日=段首日，hit15=切腿后 15 日 RS 相对收益方向正确率（fwd15 = 载体(t+15)/载体(t)−1）；信号触发<5 次不上岗；分段披露 2006-2015 / 2016-2026。

### 2.4 组合预览六变体（Part C）

执行口径：T+1 收盘执行、零成本、MA15 门为自算近似（Mmicro>MA15；原版 v6a_def 的 MA15_on_f0 门在 A9 引擎）：

- A 纯微盘（对照）
- B 门控微盘、门外现金（≈v6a_def 近似，对照）
- C 纯轮动不设门（对照）
- D 门内轮动：门开时按 ma60 在 micro/large 间轮动，门关时空仓
- E 门内轮动（ma5_20 版）
- F 永仓轮动：门关（空仓态）时持大盘而非现金——检验"空仓态换大盘"

### 2.5 估值差信号数据缺口（如实披露）

估值差（大盘/微盘 PE 分位差，均值回归逻辑）原为候选信号家族之一。实证：macro/index_valuation.parquet 仅含 hs300 PE 三口径；微盘域估值无数据源（fetch_log 实证中证500 全源失败，akshare 接口漂移 index_value_hist_funddb 已移除）。**估值差信号降级为二阶段候选**（需从 financial 数据 PIT 构造微盘池 PE，工程量不小）。外部 web 检索本轮不可用，框架映射改为体系内盘点（R-218/R-227/R-230），无外部引用。

## 三、核心发现（结论先行）

### 3.1 总判定：立项（窄口径）

- **采纳方向**：RS 趋势轮动进入 v6a_def **持仓态内部**（门开时 micro↔large 二态轮动，门关时保留现金）。
- **证否方向**：空仓态换大盘（F 变体）不可行。

### 3.2 关键证据

**证据一：切 large 方向信号有效且分段稳健（4 变体一致）**

切向 large 后方向正确率（hit15/hit60）：

| 信号 | 触发次数 | hit15 全期 | hit15（2016-2026） | hit60 全期 |
|------|---------|-----------|--------------------|-----------|
| ma20 | 238 | 55.0% | 58.4% | 65.6% |
| ma60 | 120 | 59.2% | 65.2% | 67.5% |
| mom60 | 116 | 57.8% | 58.1% | 68.1% |
| ma5_20 | 135 | 59.3% | 60.0% | 63.7% |

切 large 后 60 日平均 RS 变动：ma60 −3.51%、ma5_20 −2.65%、mom60 −2.07%（负=large 跑赢=方向正确）。2016-2026 段普遍强于 2006-2015 段（ma60 段内 hit15 达 65.2%）。

**证据二：门内轮动 D/E 相对门控微盘 B 年化 +2.5pp，Calmar 持平**

2016-2026 分段（关键决策段）：

- B 门控微盘：ann 14.5% / MDD −20.69% / Calmar 1.541
- D 门内轮动 ma60：ann 16.9% / MDD −22.99% / Calmar 1.532
- E 门内轮动 ma5_20：ann 17.1% / MDD −22.67% / Calmar 1.564

全期 D ann 35.22%/MDD −22.99%/Calmar 1.532，E ann 35.46%/−22.67%/1.564，与 B（31.90%/−20.69%/1.541）相比：近十年每年多约 2.5pp 收益，代价是 MDD 深约 2pp，Calmar 基本持平。属"加收益不加杠杆风险"的边际改善。

**证据三：空仓态换大盘不可行（F 变体证否）**

F 永仓轮动（门关时持大盘）：全期 ann 34.61% 但 **MDD −66.33%** / Calmar 0.522，与 C 纯轮动（MDD −69.25%）几乎同样不可接受。根因：系统性熊市（2008/2011-2014/2015/2022-2026）中 micro/large 同跌（日收益相关 0.864），空仓现金的防守价值无法被大盘腿替代；Mlarge 自身 MDD −69.17%。MA15 门+现金（B）之所以 MDD 仅 −20.7%，正是因为门外资金彻底离开风险资产。

**证据四：2024-01/02 微盘踩踏——"事前在位"可躲**

2024Q1 窗口：micro −24.7% vs large +0.6%；ma60 large 态占比 75.7%，MA15 门 risk-off 占 75.7% → 复合 D 该段大部分时间持 large 或现金。episode 明细：ma60 于 **2024-01-15 进入 large 态**（持续至 2024-07-31，131 天），段首 15 日 micro −35.6% vs large −12.6%（hit15/hit60 均 True）；mom60 于 2024-01-18 进入 large（至 2024-05-14，73 天）；ma5_20 于 2024-01-16 进入（至 2024-03-05，30 天）。注意 R-231 已记录 2024-02-05 当日全家族择时信号漏报——轮动腿的躲过属"**事前在位**"（段内大部分时间已处 large 态）而非"当日响应"，这一机理差异应在正式回测中如实呈现。

**证据五：2026 流动性枯竭段——立项的核心场景**

2020-09-02 峰至 2026-07-22 谷：micro **−53.4%** vs large **+195.7%**（风格极端分化）；ma60 large 态占比 73.8%，MA15 门 risk-off 50.5%。episode 明细：ma60/mom60 自 **2025-08-13 持续 large 态至 2026-08-14**（244 天，fwd60 hit True）；ma5_20 在 2026 年内多次确认 large（2026-02-25~07-15 连续 96 天）。RS 趋势腿在整个枯竭段持续指向 large，此防护价值不可由 v6a_def 空仓防守替代——这是窄口径立项的存在性证据。

**证据六（反例披露）：2017 蓝筹年轮动 miss**

2017 窗口：micro +24.2% > large +13.4%，轮动该年 large 态仅 44%，属机会成本。但 qfq 池无退市股，本口径 micro +24.2% 或高估（退市处理敏感化后再论），且错失成本=留在 large（非亏损），不构成否决项。

**已知弱点（首要优化项）：切回 micro 方向信号弱**

切回 micro 后 hit15 仅 46-52%（近似抛硬币），hit60 仅 32-38% → re-entry 确认规则是 A12 批次第一优化项（候选：连续 k 日确认 / RS 双阈值 / NMTAP·QVIX 门，接 R-230 D3/D4）。

### 3.3 影子组合与切换频率

纯轮动无门影子（零成本 T+1）：ma60 ann 31.3%/MDD −69.3%，切换 240 次（年均 11.6 次）；ma20 年均 23.1 次过频弃用。切换 240 次量级对成本敏感，正式版必做成本敏感性。

### 3.4 计算事故与修复（如实披露）

- F 变体首版结果 ann −21%/MDD −99% 为 bug：`gate` 为 object dtype（bool Series shift 后 fillna 所致），`~gate` 逐元素 Python 取反得 −1/−2，污染 `(~gate)*r_large` 项；B/D/E 因乘零项幸免。`gate.astype(bool)` 修复重跑后 F 恢复合理值，其余变体逐位不变。教训：bool Series shift 后必须显式转回 bool。
- Part A 曾因脚本缩进补丁逃逸块循环导致只扫描 2022 后数据（作废重跑）；三轮重跑关键总量与首轮一致（5030 天，corr 0.9999992 仍 PASS）。

### 3.5 n_trials 登记（防多重检验偏倚）

- Part B 信号变体扫描 4（ma20/ma60/mom60/ma5_20）；
- Part C 复合组合假设 3（D/E/F；A/B/C 为对照不计数）；
- **合计 n_trials = 7**。
- 约束延续：正式回测若选 ma60 单一主信号+确认规则，须在 locked 段复验，holdout 只看一次。

## 四、结论与建议：A12 批次设计概要

### 4.1 立项范围（窄口径）

RS 趋势轮动进 v6a_def 持仓态（micro↔large 二态），空仓态保留现金。否决记录在案：空仓态换大盘（F）MDD −66.3% 不可行。

### 4.2 正式回测口径

1. 载体：门控微盘池（v6a_def 架构）+ large 腿 = 每日 mcap 前 20% 等权（与 micro 腿同一 lexsort 流式实现）；
2. 信号：RS=Mmicro/Mlarge 的 MA60 趋势态（主）/ MA5-20（副），日频信号 + A9 月频调仓门沿用；
3. 用 A9 引擎**原版 MA15 门**（MA15_on_f0）替换本报告自算近似门；
4. 回测窗口与 R-230 一致：locked 2006-01~2024-06 / holdout 2024-07~2026-08。

### 4.3 防过拟合约束

- ma60 定为单一主信号（依据：hit15 59.2%、2016-2026 段 65.2%、切换频率适中），不再网格搜索信号族；
- re-entry 确认规则在 locked 段内定型，holdout 只评估一次；
- n_trials 台账延续累计（本轮已计 7）。

### 4.4 必做敏感性与二阶段候选

- 成本敏感性（切换 240 次级频率，双边成本×若干档）；
- 退市股处理敏感化（qfq 池幸存者偏差对 micro 腿 2017/2024 段的影响）；
- 估值差信号降级二阶段候选（微盘域 PE 无源已实证，需 financial 数据 PIT 构造或另接源）；
- 对照披露：2017 蓝筹年 miss 与 2024-02-05"事前在位 vs 当日响应"机理差异。

### 4.5 晋升路径

1. A12 正式回测（上述口径）→ locked 段 Calmar ≥ B 基线（1.54 附近）且 ann 增益保留 → 进入 holdout 验证；
2. holdout 单次评估通过 → 并入 v6a_def 演进版本（macro_timing_layer 新增 RS 分支，状态机 micro/large 二态）；
3. 未通过 → 归档为"已证伪的方向分化防护"复盘材料，n_trials 不清零。
