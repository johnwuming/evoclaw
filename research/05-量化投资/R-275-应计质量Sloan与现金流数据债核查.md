## 一、数据债修正口径：44.5% 是宇宙污染假象，A 股真债 ≈ 0-3.4%

**结论先行：不需要补采现金流数据。** fin_deep 现金流列广度 44.5% 的根因是 yjbb（业绩报表接口）把非 A 股代码带入面板分母：

| 构成（20251231 期实测，前序阶段A） | 数量 |
|---|---|
| yjbb 总行数 | 11,518 |
| xjll/zcfz/lrb（纯 A 股） | 5,228 |
| 差额中：新三板（83/87/43/92 前缀） | 6,062 |
| 老三板/两网退市（40/42）+ B 股（900/200） | 203 |
| **A 股主流前缀（00/30/60/68）缺失** | **0** |

5244/11765 = 44.57%，精确复现 R-266 的 44.5%。修复方式 = merge 前按 code 前缀/参照宇宙过滤（一处改动，factor_expansion_v3ak.py load_ak_wide），无采集成本。

本阶段 VPS 本地重采验证（EM 同源接口，2005Q1~2026Q2 × 86 期 × 3 表，A 股前缀过滤后 yjbb 288,275 行 / zcfz 280,143 / xjll 288,715）：

- **三要素（净利∧经营现金流∧总资产，同期齐全）覆盖率：全史 96.6%，近 3 年 99.4%**；xjll OCF 近 3 年覆盖 99.9%。
- 分年齐全率全部 ≥91%（最低 2009 年 91.1%，IPO 密集期），近年 ≥99%（明细 `r275/breadth_a_share.csv`）。
- 残余缺口：yjbb 有净利但 xjll 无该行的 A 股期次 86 期共 807 例 = 0.28%，集中 2005-2011（源端真缺/脏行，量级可忽略）。
- PIT 现状：usable_from = max(法定披露期限, pubDate)+1；实测 EM 老期 pubDate 为库回填日（如 2015 年报 pubDate 集中 2017）→ 保守无前视但可见性滞后 1-2 年。

**Sloan 可用起始：2006 年**（TTM 需 4 个连续季度，首年 2006 出现 3,497 条 usable 观测；可用面板 2006Q1~2026Q2 共 240,255 条）。

## 二、Sloan 应计 IC 验证（W1 口径：月频全市场 spearman，MAD3 去极值+zscore，n≥200，上市≥120 日）

accrual = (NP_TTM − OCF_TTM) / TA_当期；Sloan 原意为**负向**（高应计→未来收益低）。

## 三、判定：**维持关闭**（三选一）

不立项 E1、数据债不构成阻断。理由：

1. **IC 弱**：两口径 |IC| ≤ 0.011，ICIR 0.11~0.14，|t| < 1.8，全样本不显著；W1 体系在役因子门槛（通常 IC≥0.02~0.03 且 t>2）远未达到。
2. **不稳健**：严格 PIT 下应计 IC 为正（反 Sloan 方向），deadline-PIT 下为负（顺 Sloan）——结论对 PIT 假设敏感，符号翻转本身就是危险信号；deadline-PIT 的分组也不单调。
3. **数据债已修**：44.5% 是宇宙污染，修复成本≈0（merge 前前缀过滤）。这不影响未来其他财务因子继续使用 fin_deep 管线（该修复建议登记为管线任务，非本因子）。

归档建议：若未来做「财务质量组合因子」，Sloan 应计可作为低冗余正交特征（|corr|≈0.10）重新入池，但单因子形态无立项价值。
