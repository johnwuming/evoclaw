### 1.2 数据管线（Data Pipeline）

**现状**: ✅ 已有5205只A股日K线（parquet）+ 同花顺财务数据
**问题**: ⚠️ AKShare不稳定、数据更新机制未自动化、缺少数据质量校验

#### 数据流

```
AKShare / 同花顺 API
       │
       ▼
  ┌──────────┐     ┌──────────────┐     ┌──────────────┐
  │ 数据获取  │────▶│  数据清洗     │────▶│  数据存储     │
  │ fetch_*. │     │ 去重/对齐/   │     │ parquet      │
  │ py       │     │ 前复权/停牌   │     │ data/        │
  └──────────┘     │ 标记          │     └──────┬───────┘
       ▲           └──────────────┘            │
       │                                        ▼
  ┌────┴─────┐                          ┌──────────────┐
  │定时任务   │                          │ 数据快照     │
  │ cron     │                          │ snapshot/    │
  │ 每日18:00│                          │ (月频冻结)   │
  └──────────┘                          └──────────────┘
```

#### 数据资产清单

| 数据集 | 路径 | 格式 | 记录数 | 更新频率 | 状态 |
|--------|------|------|--------|----------|------|
| A股日K线（前复权） | `data/all_stocks_qfq/` | parquet | 5205只 | 需手动 | ⚠️ |
| 同花顺财务数据 | `data/financial-ths/` | parquet/csv | 待确认 | 需手动 | ⚠️ |
| 指数数据（沪深300等） | `data/*.parquet` | parquet | ~5个 | 需手动 | ⚠️ |
| ST/退市标记 | — | — | — | — | ❌ 缺失 |
| 涨跌停数据 | — | — | — | — | ❌ 缺失 |
| 行业分类 | — | — | — | — | ❌ 缺失 |

#### 缺失环节

1. **自动更新机制**: 需要一个 `data_update.py` 脚本 + cron 定时任务
2. **数据质量校验**: 缺失值检测、异常值标记、数据连续性检查
3. **增量更新**: 当前可能是全量拉取，需要改为增量模式
4. **交易日历**: 需要维护一个权威交易日历（过滤非交易日）
5. **ST/退市/涨跌停处理**: 回测中必须过滤这些情况，否则结果虚高

### 1.3 因子体系（Factor System）

**现状**: ✅ 7个种子因子IC检验完成，反转因子最强（IC=-0.39）
**问题**: ⚠️ 多因子增强稀释alpha、因子库管理不完善、缺少衰减机制

#### 因子生命周期

```
   ┌─────────────┐
   │ LLM 因子假设 │
   │ (Hypothesis)│
   └──────┬──────┘
          │
          ▼
   ┌─────────────┐     不通过      ┌──────────┐
   │ 代码生成     │──────────────▶│ 淘汰     │
   │ (Code Gen)  │               │ (Reject) │
   └──────┬──────┘               └──────────┘
          │ 通过
          ▼
   ┌─────────────┐     IC < 阈值   ┌──────────┐
   │ IC 检验      │──────────────▶│ 淘汰     │
   │ (IC Test)   │               │ (Reject) │
   └──────┬──────┘               └──────────┘
          │ IC ≥ 阈值
          ▼
   ┌─────────────┐
   │ 分层回测     │
   │ (Layered)   │
   └──────┬──────┘
          │ 单调性通过
          ▼
   ┌─────────────┐
   ★ 入库 (Active) ★
   └──────┬──────┘
          │
          ▼
   ┌─────────────┐     衰减检测      ┌──────────┐
   │ 月度复检     │──────────────▶│ 降权/淘汰│
   │ (Monthly)   │   IC连续3月    │ (Decay)  │
   └─────────────┘   低于阈值       └──────────┘
```

#### 因子库结构

```json
{
  "id": "reversal_5d",
  "name": "5日反转",
  "category": "price_reversal",
  "status": "active",        // active / decayed / rejected
  "ic_mean": -0.039,
  "ic_ir": 1.85,
  "ic_history": [...],
  "weight": 1.0,
  "source": "seed",          // seed / llm / manual
  "created_at": "2026-07-01",
  "last_check": "2026-08-09",
  "decay_count": 0,
  "llm_hypothesis": "",
  "code_ref": "scripts/factors/reversal_5d.py"
}
```

#### 当前因子IC检验结果（Phase 2）

| 因子 | IC均值 | ICIR | 评价 |
|------|--------|------|------|
| 5日反转 | -0.039 | 1.85 | ✅ 强有效 |
| 10日反转 | -0.035 | 1.65 | ✅ 有效 |
| 20日反转 | -0.028 | 1.30 | ✅ 中等 |
| 换手率 | ~-0.02 | ~1.0 | ⚠️ 弱 |
| 波动率 | ~-0.015 | ~0.8 | ⚠️ 弱 |
| 量价比 | ~-0.01 | ~0.5 | ❌ 不显著 |
| 市值 | ~-0.05 | ~2.0 | ✅ 强（但与小市值策略共线） |

> **关键发现**: 多因子组合时 alpha 被稀释，说明因子间存在共线性或噪音干扰。

#### 缺失环节

1. **因子正交化**: 多因子合成前需要正交化处理（Schmidt正交或PCA）
2. **因子衰减监控**: 每月复检IC，连续3月低于阈值自动降权
3. **因子相关性矩阵**: 入库前检查与已有因子的相关性
4. **因子分类体系**: alpha因子 vs 风险因子 vs 噪音因子

### 2.2 是否需要增加专门的 Agent？

```

  - 代码生成:     ~3000 tokens (input) + ~2000 tokens (output)
  - 验证反馈:     ~2000 tokens (input) + ~500 tokens (output)

DeepSeek V4 Flash定价（reasoning模式）:
  - Input: ¥0.001/1K tokens
  - Output: ¥0.002/1K tokens
  - 单次成本: ~7K*0.001 + 3.5K*0.002 = ¥0.014
  - 月度成本: ~¥0.014
  - ¥100充值可支持: ~7000次进化循环（绰绰有余）
```
