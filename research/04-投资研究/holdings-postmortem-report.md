### 2b. 涨好组（33 笔） vs 非涨好组（1236 笔）

| 特征 | 涨好组中位 | 全体中位 | 差异 | Welch p |
|---|---|---|---|---|

→ **涨好组的画像：显著更小市值（小盘高弹性）、ROA 更低（同为小盘弹性特征）、买入时动量略正**。

### 2c. 核心不对称

小市值**同时**驱动赢家与输家（输家组 mv_pct 中位也低，仅不显著）。因此杠杆不在"市值本身"，而在**市值 × 质量/动量**：小盘 + 趋势健康 → 赢；小盘 + 高股息陷阱/深度回撤 → 输。

### 2d. 退市/强平持仓专项（SELL_FORCED_DELIST，11 笔）

- **全部 11 笔 is_delisted_code=0（不在 361 只退市索引内）** → 这些是引擎级强制卖出（ST/停牌/退市风险强平），非真退市；全样本真正命中退市索引的持仓仅 1 笔（收益 -1.8%）。
- 强平笔特征（买入时）：002027（大市值 ROE 0.31）亏 -38%；300824（小市值、流动性分位 0.037 枯竭）亏 -12%；603551（流动性 0.022 枯竭）小亏；其余小赚小亏。
- **警示**：最大单笔损失 -38% 来自"高 ROE 大盘股 002027 突停/强平"，属于常规退市预警（ROE 衰减、股价趋 1 元、流动性枯竭）筛不掉的事件型风险。
- 持仓时长：输家中位 166 天 vs 赢家中位 304 天 vs 全体 63 天 → 赢家拿得住，输家平均僵持更久。

## 5. ledger 特征标注规范（供 A5+ 使用）

每次迭代记录（迭代行）必须新增 `features` 字段，JSON 结构如下，用于后续批次的输赢归因与规则回溯：

```json
"features": {
  "dimensions_changed": ["exclusion/E1", "enhancement/G2"],
  "factors_introduced": ["ret120", "dist250h", "amount20_pct", "dy_pct"],
  "rules_added": [{"id": "E1", "type": "exclude", "cond": "ret120 < -0.30", "evidence": "cut 20.8% loss tail / kill 12.1% winners"}],
  "rules_removed": [],
  "mechanism_hypothesis": "高股息陷阱：dy 高 + 动量枯竭 → 下跌中继；小盘 + 趋势健康 → 高弹性",
  "pit_note": "特征一律取买入日 PIT；无权重数据时回撤贡献用尾部收益 proxy",
  "source_task": "task-0331"
}
```

规范要点：① 每次改选股逻辑必须写本字段；② 因子一律按"买入时点已知"口径标注；③ 规则必须附证据数字（亏损尾部占比 / 误杀赢家占比）；④ 机制假设用一句话写清（便于 A5+ 判断是否值得做正交测试）；⑤ 新规则上线时在 `rules_added` 里同时登记"在哪一迭代引入、依据哪个复盘 task"。

## 6. 对 A4 的即时建议（A4 正在跑价值大师指标）

- **加**：动量/趋势维度（ret120、dist250h）作为价值指标的**正交护栏**——价值大师（低估值型）天然会把 dy_pct 高分位选进来，而本复盘证明"高股息 + 动量枯竭"正是跌深组最强画像（E3 捕获 34.9% 亏损尾部）。**若 A4 结果出来后，建议给价值因子加"动量护栏"（ret120>-30% 硬过滤，或 E3 降权），可预期砍掉约 1/5~1/3 亏损尾部。**
- **加**：流动性下限（amount20_pct<10% 弱排除或降权），兼顾强平风险（300824/603551 均为流动性枯竭后被强平）。
- **删/慎用**：不要单用市值分位做排除（微盘尾误杀 64% 赢家）；价值大师若输出"超小市值纯价值"信号，必须叠加趋势健康条件（G5 方向），否则会把价值陷阱当便宜货。
- **保留**：roe_ttm<0 硬过滤（当前 universe 已自动排除，仅 2 笔，维持即可）。
- **提示**：002027 这类"高 ROE 大盘突停"事件型风险，价值因子无法前置识别，建议在 paper_engine 层面对强平损失的暴露单独监控，不纳入价值因子调参目标。
