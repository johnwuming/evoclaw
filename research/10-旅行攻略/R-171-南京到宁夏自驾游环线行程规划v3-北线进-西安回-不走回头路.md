## 🔋 乐道L60 补能策略总述

### 车辆参数
- CLTC续航：555km
- 高速实际续航（120km/h、空调开）：约 380-420km
- 换电时间：约 3-5 分钟（第三代站）
- 支持快充：800V 高压平台，10%-80% 约 20 分钟

### 换电站/充电桩沿途分布（基于2025年网络布局）

| 城市 | 换电站情况 | 备注 |
|------|----------|------|
| 南京 | 密集（10+站） | 出发前满电 |
| 合肥 | 乐道换电站 3-5 座 | 滨湖/政务区有站 |
| 洛阳 | 乐道换电站 1-2 座 | 高速服务区有国网充电桩 |
| 临汾/壶口 | 暂无换电站，服务区快充可用 | 建议洛阳满电出发 |
| 延安 | 乐道换电站 1 座（规划中） | 服务区快充补充 |
| 银川 | 乐道换电站 2-3 座 | 充电桩充足 |
| 中卫 | 暂无换电站，酒店/景区充电桩可用 | 快充为主 |
| 平凉/西安方向 | G70沿线服务区快充密集 | 国家电网覆盖好 |
| 西安 | 乐道换电站 3-5 座 | 城区内有多座 |
| 南阳 | 乐道换电站 1 座（规划中） | 服务区快充 |

### 补能黄金法则
1. **每日出发前**：确认电量 > 80%
2. **高速午餐时**：趁吃饭快充 30 分钟（补 200km+）
3. **到酒店后**：连夜慢充至满电
4. **换电优先**：有换电站的城市（合肥、洛阳、银川、西安）优先换电
5. **备用方案**：下载「e充电」「星星充电」APP，覆盖国网/第三方桩

> ⚠️ 山西南部（临汾-壶口段）和宁夏中卫换电覆盖较弱，建议在这些路段前保持 80% 以上电量。

## 📅 逐日行程

---

### D1：南京 → 合肥（🔵去程北线）

| 项目 | 详情 |
|------|------|
| **里程** | 160km |
| **驾驶时间** | 约 2 小时 |
| **路线** | 南京→G36宁洛高速→合肥绕城 |
| **补能** | 南京出发满电；合肥乐道换电站补能 |

#### 上午
- **08:30** 从南京出发，走 G36 宁洛高速南下
- **10:30** 抵达合肥，办理入住

#### 下午
- **14:00** **安徽省博物院**（新馆） — 免费参观，有青铜器和恐龙化石展厅，3岁小朋友对恐龙骨架很感兴趣
  - 亲子友好度：⭐⭐⭐⭐ 推楼层有互动区
- **16:00** **天鹅湖公园** — 免费开放式公园，可以散步看湖景，小朋友可以跑跑跳跳

#### 晚上
- **18:00** 晚餐：**合肥老母鸡汤** / **李鸿章大杂烩** / **宁国路龙虾街**
- 推荐：到**罍街**（léi jiē）美食街 — 合肥最有烟火气的夜市，各种小吃

#### 住宿建议
- **中档**：合肥政务区/滨湖新区酒店（300-400元/晚），靠近换电站
- **经济**：合肥火车站附近连锁酒店（150-200元/晚）

### D2：合肥 → 开封 → 洛阳（🔵去程北线）

| 项目 | 详情 |
|------|------|
| **里程** | 约 560km（合肥→开封 360km + 开封→洛阳 200km） |
| **驾驶时间** | 约 6 小时（含中途停留） |
| **路线** | 合肥→G36→开封→G30连霍高速→洛阳 |
| **补能** | 合肥出发满电；开封服务区快充30min；洛阳换电站补能 |

#### 上午
- **07:00** 合肥出发，G36 北上
- **11:00** 抵达**开封**，游览**清明上河园**
  - 以《清明上河图》为蓝本的大型宋代主题公园
  - 门票参考：成人 120元，1.2m以下儿童免费
  - 特色：实景宋代街市，有汴绣、杂耍表演
  - 亲子友好度：⭐⭐⭐⭐⭐ 小朋友可以看表演、坐小船、穿古装拍照

#### 下午
- **13:30** 开封午餐：**灌汤包**（第一楼最出名）、**桶子鸡**、**炒凉粉**
- **14:30** 开封出发前往洛阳
- **17:00** 抵达洛阳，入住酒店

#### 晚上
- **18:30** **洛阳老街/十字街夜市** — 河南最有味道的夜市之一
  - 推荐：**洛阳水席**（连汤肉片、牡丹燕菜），**浆面条**，**不翻汤**
- **20:00** 如果不累，可去**洛邑古城**看夜景（免费入园）

#### 住宿建议
- **中档**：洛阳老城区/西工区精品酒店（300-500元/晚）
- **经济**：洛阳火车站附近连锁酒店（150-250元/晚）

#### 换电提示
洛阳有乐道换电站（建议到洛阳后先换电，为明天壶口之行做准备）。

---

### D3：洛阳 → 壶口瀑布 → 延安（🔵去程北线）

| 项目 | 详情 |
|------|------|
| **里程** | 约 380km（洛阳→壶口 230km + 壶口→延安 150km） |
| **驾驶时间** | 约 5 小时（含壶口停留） |
| **路线** | 洛阳→G30→二广高速→G22→壶口→G22→延安 |
| **补能** | 洛阳出发满电（>90%）；壶口/临汾服务区快充；延安酒店慢充 |

#### 上午
- **07:30** 洛阳出发，走 G30 连霍高速转 G22 青兰高速
- **10:00** 抵达**黄河壶口瀑布**（山西侧吉县）
  - 🌊 世界上最大的黄色瀑布，黄河在此收窄至30米宽倾泻而下
  - **门票参考**：成人 100元/人（含景区观光车），1.2m以下儿童免费
  - **开放时间**：07:00-18:30（夏季）
  - 景色震撼，水雾弥漫，彩虹频现
  - 亲子友好度：⭐⭐⭐ 噪音较大可能吓到小朋友；注意安全栏杆外不要靠近
  - ⚠️ 备雨衣/防水外套，水雾很大

#### 下午
- **12:30** 壶口附近午餐（农家乐：黄河鲤鱼、荞麦面）
- **13:30** 出发前往延安，走 G22 青兰高速
- **16:00** 抵达延安

#### 晚上
- **17:00** **宝塔山**（延安标志） — 登山看延河与宝塔
  - 门票参考：成人 65元/人
- **18:30** 晚餐：**延安擀面皮**、**子长煎饼**、**羊肉面**
- **20:00** 可去**延安红街**散步（免费），感受红色文化

#### 住宿建议
- **中档**：延安市区宝塔区酒店（250-350元/晚）
- **经济**：延安老城区连锁酒店（120-200元/晚）

#### 换电提示
延安换电覆盖规划中，建议洛阳满电出发。壶口瀑布附近的吉县服务区有国网快充桩。到延安后连夜慢充。

### D4：延安 → 银川（🔵去程北线）

| 项目 | 详情 |
|------|------|
| **里程** | 约 450km |
| **驾驶时间** | 约 5.5 小时 |
| **路线** | 延安→G65包茂高速北行→G20青银高速→银川 |
| **补能** | 延安出发满电；靖边/定边服务区快充30min；银川换电站补能 |

#### 上午
- **07:00** 延安出发，走 G65 包茂高速向西北方向
- **10:00** 途经**靖边波浪谷**（可选停留 2-3 小时）
  - 🏜️ 陕北丹霞地貌，红砂岩峡谷，酷似美国波浪谷
  - 门票参考：成人 90元/人
  - 亲子友好度：⭐⭐⭐ 需要步行，有台阶；注意防晒
  - 如不停留可提前到银川

#### 下午
- **13:00** 服务区午餐（自热饭/泡面/简餐），或在**定边**县城吃一顿陕北羊肉
- **14:00** 继续赶路，进入宁夏界
- **15:30** 抵达**银川**

#### 晚上
- **16:30** 入住酒店休整
- **18:00** 晚餐：**银川夜市** — 推荐**怀远夜市**
  - 必吃：辣条（怀远一品）、烤羊肉串、羊杂碎、手抓羊肉、八宝茶
  - **银川的羊肉是全程最好的之一**
- **20:00** 去**银川阅海/凤凰公园**散步消食

#### 住宿建议
- 银川住宿建议以**兴庆区/金凤区**为基地（连续住4晚），选带停车+充电桩的酒店
- **中档**：银川金凤万达附近酒店（300-450元/晚）
- **经济**：兴庆区连锁酒店（150-250元/晚）

### D5：银川西线 — 镇北堡西部影城 + 贺兰山岩画（🟢宁夏深度）

| 项目 | 详情 |
|------|------|
| **里程** | 约 60km（市区往返） |
| **驾驶时间** | 约 1.5h（含往返） |
| **补能** | 银川换电站满电；酒店慢充 |

#### 上午
- **09:00** 出发前往**镇北堡西部影城**（距市区约40km）
  - 🎬 张贤亮创办，《大话西游》《红高粱》《新龙门客栈》拍摄地
  - 分清城、明城、老银川一条街三个区域
  - **门票参考**：成人 80元/人（网购约 60-70元），1.2m以下儿童免费
  - **开放时间**：08:00-18:00
  - 特色：可以租紫霞仙子/至尊宝服装拍照，实景拍摄地巡礼
  - 亲子友好度：⭐⭐⭐⭐ 场景有趣如穿越；但部分区域地面不平，注意推车

#### 中午
- **12:30** 影城内"老银川一条街"吃午餐（仿民国风格餐厅）
  - 推荐：羊肉搓面、烩肉

#### 下午
- **14:30** 前往**贺兰山岩画景区**（距影城约 20km）
  - 🗿 世界级岩画遗址，远古游牧民族的艺术长廊
  - **门票参考**：成人 70元/人（含观光车），儿童 1.2m以下免费
  - 特色：太阳神岩画是标志；可以看到野生岩羊（小朋友会很兴奋！）
  - 亲子友好度：⭐⭐⭐⭐ 有岩羊出没，小朋友喜欢找动物

#### 晚上
- **17:30** 返回银川市区
- **18:30** 晚餐：**老毛手抓羊肉**（银川百年老店）或 **国强手抓**
  - 必点：手抓羊肉、蒜泥羊头、八宝茶

### D6：银川北线 — 沙湖 + 西夏陵（🟢宁夏深度）

| 项目 | 详情 |
|------|------|
| **里程** | 约 120km（往返+两景点间） |
| **驾驶时间** | 约 2h |
| **补能** | 银川换电站/酒店慢充 |

#### 上午
- **08:30** 出发前往**沙湖**（距银川约 60km，平罗县）
  - 🏞️ 沙漠与湖泊交汇的奇观，一半沙一半水
  - **门票参考**：成人 130元/人（含大船票），儿童 1.2m以下免费
  - 网购套票（门票+船票+电瓶车）：约 130-150元
  - **开放时间**：08:00-17:30
  - 特色：坐船穿湖而过，沙丘上可以骑骆驼、滑沙
  - 亲子友好度：⭐⭐⭐⭐⭐ 坐船 + 滑沙 + 看鸟类，小朋友的天堂
  - ⚠️ 带防晒霜、遮阳帽

#### 中午
- **12:30** 沙湖景区内午餐（沙湖大鱼头是招牌菜）
  - 推荐：**沙湖鱼头泡饼**（花鲢鱼头，鲜嫩肥美）

#### 下午
- **14:30** 前往**西夏陵**（距沙湖约 70km，银川西郊）
  - 👑 "东方金字塔" — 西夏王朝皇家陵园
  - 📢 **2025年新晋世界文化遗产！**（中国第60项世界遗产）
  - **门票参考**：成人 75元/人（含观光车），儿童 1.2m以下免费
  - 网购含博物馆+遗址区：约 85-95元
  - 特色：9座帝陵 + 200余座陪葬墓，背靠贺兰山
  - 博物馆有西夏文展示、3D重现西夏宫殿
  - 亲子友好度：⭐⭐⭐ 偏历史文化，小朋友可能觉得枯燥；但可以在陵塔前跑跑

#### 晚上
- **17:30** 返回市区
- **18:30** 晚餐：**同心春**（宁夏特色炒菜）或去**大阅城**美食广场
  - 推荐：炒烩肉、羊排小揪面、枸杞苗

### D7：银川东线 — 水洞沟（🟢宁夏深度）

| 项目 | 详情 |
|------|------|
| **里程** | 约 50km（往返） |
| **驾驶时间** | 约 1h |
| **补能** | 银川换电站满电 |

#### 上午
- **09:00** 出发前往**水洞沟古人类文化遗址**（距银川约 30km，灵武市）
  - 🏺 中国最早发现的旧石器时代遗址之一，5万年前人类活动地
  - **门票参考**：成人 130元/人（含观光车+游船+骆驼车/拖拉机），儿童 1.2m以下免费
  - 网购套票：约 110-130元
  - **开放时间**：08:00-18:00
  - 特色：考古遗址 + 藏兵洞（明代地下军事防御工事）+ 红山湖
  - 最大亮点：**藏兵洞探险** — 地下隧道，小朋友会觉得像寻宝探险！
  - 亲子友好度：⭐⭐⭐⭐ 藏兵洞探险是亮点；但洞穴较暗，注意带手电筒/牵好孩子

#### 下午
- **13:00** 景区内午餐或回市区吃
- **14:30** 回银川市区休整，可以带孩子去**宁夏科技馆**（免费）
  - 亲子友好度：⭐⭐⭐⭐⭐ 有互动实验、球幕影院，适合避暑

#### 晚上
- **18:00** 晚餐：**银川南门清真大寺**附近美食街
  - 推荐：羊杂碎汤（配馍馍）、烩羊肉、馓子
- **19:30** 为明天出发做准备，整理行李，早点休息

#### 补能提示
今天在银川换电站充满至 100%，为明天银川→中卫 200km 的行程做准备。

### D8：银川 → 青铜峡 → 中卫（🟢宁夏深度）

| 项目 | 详情 |
|------|------|

  - 在黄河上漂 20-30 分钟，小朋友会觉得很有趣
- **10:00** **滑沙** — 从沙坡顶滑下，小朋友可以和家长一起坐

- **14:00** 乘坐景区交通车进入**沙漠区**

#### 🔑 带娃沙漠游玩注意事项
1. **防晒**：SPF50+防晒霜每 2 小时补涂一次；遮阳帽+太阳镜
2. **防沙**：带防沙鞋套或穿封闭鞋；湿巾多带，随时擦脸擦手
3. **补水**：人均 1.5L 水，电解质饮料也带上
4. **时间管理**：上午和傍晚活动，中午 12:00-14:00 在阴凉处休息
5. **挖沙工具**：小铲子+小桶，沙漠就是天然大沙坑，3岁娃能玩 1-2 小时
6. **沙暴预警**：如遇大风沙暴天气，景区可能关闭部分项目，提前关注
7. **体温管理**：沙漠早晚温差大（可达 15°C），带一件薄外套

## ⚠️ 重要提醒

### 暑期出行注意
1. **7-8月是西北旅游旺季**，景区和酒店务必**提前1-2周预订**
2. **兵马俑**需提前在官方公众号预约购票，暑假经常售罄
3. **沙坡头**暑假期间上午人最多，建议开门即入
4. 西北紫外线极强（海拔高+空气干燥），**防晒是第一要务**
5. 银川夏季白天可达35°C，但早晚降至20°C以下，**带薄外套**

### EV 用车提醒
1. **出发前**：检查胎压、刹车、轮胎磨损
2. **高速服务区**：充电桩高峰期可能排队，建议错峰（12:00前或14:00后）
3. **山区路段**（秦岭/壶口）：电量消耗比平原高15-20%，预留余量
4. **中卫/壶口**换电站覆盖弱，提前在银川/洛阳补满电
5. 车载空调长时间使用会增加电耗约10-15%

### 亲子出行贴士
1. **行程节奏**：长途驾驶日（>400km）安排在上午精神好时，下午到达后轻活动
2. **每2小时休息**：服务区停车让孩子跑跑，大人也缓解疲劳
3. **景区选择**：优先选有互动体验的景点（影城、沙湖、沙坡头），纯历史景点控制时长
4. **零食策略**：准备健康零食（水果切块、坚果、酸奶），少糖少添加剂
5. **拍照Tips**：沙漠穿红色/白色衣服最上镜；影城可租古装
