# A7c 动态因子有效性核验报告：滚动 IC 窗口 + 衰减/涌现分类

> 任务：task-0341 | 生成：2026-08-17 | 数据：W1 月频 IC 面板（2006-01~2026-07，247 月，107 因子）| 与 A7 全周期归因正交

## 一、方法

- **数据**：本地 W1 口径月频 IC 面板（factor_ic_monthly.csv，与 HP 同源），对每个因子取月度横截面 IC（去极值/标准化后对下月收益的 spearman），共 247 月。
- **符号**：面板存原始 IC；按 catalog v3 direction 调整为"有效 IC"（dir=neg 取反）。有效 IC 为正 = 因子按预期方向有效。
- **指标**：全周期 IC 均值 / ICIR（=均值/标准差）/ t 值；近 24m / 36m 滚动窗口 IC 与 ICIR；分段 2018-2021 vs 2022-2026；IC 半衰期（取 catalog v3 half_life_months，多期衰减拟合法）。
- **动态画像分类规则**：
  - 稳定有效：全周期 |t|≥2 且近 24m ICIR≥0.4、符号与全周期一致
  - 衰减中：全周期显著但近 24m 同号且 ICIR 明显走弱（<0.4）
  - 已失效/反转：近 24m 符号与全周期相反或近零
  - 近期涌现：全周期弱但近 24m 显著
  - 数据缺口：无 IC 面板列（择时/规则类或需新数据），以 A7 回测归因替代
