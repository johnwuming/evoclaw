# 行业最佳实践素材

## 1. A股小市值策略研究

### 策略背景
- A股小市值长期跑赢大市值，是被研究最多的量化策略之一
- 2024年6月底，小盘股和大盘股估值价差达20年来最大水平（Robeco研究）
- 2025年A股换手率和日均成交额处于较高水平，小市值因子强劲

### 小市值策略关键要素
1. **调仓频率**: 周频/月频，月频适合降低交易成本
2. **持仓数量**: 5-30只不等，20只是常见的分散度
3. **筛选条件**:
   - PB>0排除负资产公司
   - 排除ST/退市风险股
   - 排除流动性过差的标的
   - 可叠加其他因子（动量、低波动等）

### 小市值策略的风险
- **壳价值下降**: 注册制改革以来A股壳价值大幅收缩
- **2024年初规模因子(size factor)表现不佳**（因子拥挤风险）
- **政策风险**: 退市常态化，小市值股票退市风险更高
- **流动性风险**: 小市值股票流动性差，冲击成本高

### 资金量影响
- **10万级别**: 适合20只左右持仓的小市值策略，基本无冲击成本
- **果仁网标准**: 流动性分90分以上可容纳亿元级资金
- 个人小资金的优势：不受容量限制，可以参与最极端的小市值策略

## 2. A股市场特殊性

### 交易制度
- **T+1交易**: 当日买入不能当日卖出
- **涨跌停限制**: 主板±10%，创业板/科创板±20%
- **停牌处理**: 需要合理处理停牌股票
- **退市制度**: 注册制下退市常态化，2023年45家退市（43家强制退市）

### 量化回测注意事项（A股特有）
- 涨跌停处理：涨停难买入，跌停难卖出
- 向量化回测需手动检查涨跌停
- 事件驱动回测更适合策略验证
- 退市整理期通常连续下跌
- ST标记股票需特殊处理
- 新股上市初期波动大

### 市场结构特征
- 散户占比高，市场效率相对低
- 风格轮动明显（大小盘、价值成长）
- 政策敏感度高
- 行业板块效应强

## 3. 回测过拟合防范

### Walk-Forward分析（WFA）
- **核心思想**: 模拟真实时序交易，在历史样本内优化，样本外测试
- **步骤**:
  1. 选择训练窗口（如2年）
  2. 在训练窗口优化参数
  3. 在紧接的测试窗口（如3个月）验证
  4. 窗口前移，重复
- **优势**: 严格防止过拟合和前视偏差
- **2025年论文**: arxiv 2512.12924 提出了可解释假设驱动的WFA框架

### 过拟合防范清单
1. **样本外检验**: 严格分离训练/验证/测试集
2. **Walk-Forward**: 时序交叉验证而非随机交叉验证
3. **参数平原**: 检查参数敏感性，避免参数悬崖
4. **蒙特卡洛回测**: 随机打乱交易时序检验统计显著性
5. **置换检验**: 打乱标签检验策略是否显著优于随机
6. **多重检验校正**: 测试大量因子时需要Bonferroni或FDR校正
7. **IC去重**: 新因子与已有因子相关性高则丢弃（RD-Agent做法）
8. **交易成本建模**: 包含佣金、滑点、冲击成本
9. **幸存者偏差**: 包含已退市股票
10. **前视偏差**: 确保不使用未来信息

### 回测-实盘不一致问题
BigQuant 2026年私享会核心关注点：
- 蒙特卡洛回测方法
- 参数平原方法
- 交易成本建模
- 市场冲击模拟

## 4. 因子挖掘自动化流程（闭环）

### 标准流程
1. **假设生成**: LLM基于市场知识生成因子假设
2. **代码实现**: 自动生成因子计算代码
3. **回测验证**: 在历史数据上计算IC/ICIR等指标
4. **去重检查**: 与已有因子做相关性分析
5. **组合测试**: 纳入因子组合，检验增量的贡献
6. **衰减监控**: 持续监控因子表现
7. **迭代优化**: 基于反馈生成新假设

### Alpha衰减对抗策略（AlphaAgent）
- **原创性强制**: AST相似度检查防止因子同质化
- **假设-因子对齐**: 确保因子有经济学逻辑
- **复杂度控制**: 防止过度工程化的因子构造

### 因子评价体系
- **预测力**: IC（信息系数）、Rank IC
- **稳定性**: ICIR（IC信息比率）
- **策略表现**: ARR（年化超额收益）、SR（夏普比率）、MDD（最大回撤）
- **独立性**: 与已有因子的相关性
- **衰减速度**: 滚动IC变化趋势

## 6. 个人/小团队AI量化实践建议

### 成功要素
1. **聚焦**: 选一个方向做深（如小市值+因子增强）
2. **简约**: 因子不在多，在精
3. **严谨**: 回测纪律比策略创意更重要
4. **迭代**: 持续监控和调整
5. **风控**: 永远把风控放在第一位

### 常见误区
1. 过度拟合历史数据
2. 忽略交易成本
3. 因子过多导致过拟合
4. 忽略市场环境变化（regime shift）
5. 盲目追求复杂模型
6. 低估LLM幻觉风险

### 推荐工具链（无GPU环境）
- 数据: AKShare/Tushare（A股数据）
- 回测: Qlib/vectorbt
- 因子挖掘: RD-Agent + DeepSeek API
- 模型: LightGBM/CatBoost（CPU友好）
- 文本分析: FinGPT/DeepSeek
