### 1.2 关键利润转折点

- **2019年：** 调整口径下首次实现全年盈利（调整后归母净利润约0.21亿元），标志着公司从多年亏损中走出
- **2022年：** 首次实现IFRS（国际财务报告准则）口径全年盈利——CFO颜劲良特别强调这是"里程碑事件"
- **2023年：** 调整后归母净利润同比暴增233.2%至3.70亿元，AI驱动的订阅收入成为核心引擎
- **2024年：** 出售全部加密货币，获得一次性收益约6.4亿元（非经营性）
- **2025年：** 调整后净利润达9.65亿元，连续第七年增长；IFRS口径净利润因可比基数（2024年加密货币出售收益）及可转债非现金费用（约5.12亿元）而下降不超过30%

## 二、收入结构演变：从硬件到AI订阅

### 2.1 收入结构变迁四阶段

```
阶段一（2016–2018）：硬件 + 广告
  → 美图手机（硬件）贡献主要收入，广告为辅
  → 2018年硬件收入高峰，但亏损扩大

阶段二（2019–2021）：战略转型期
  → 逐步退出手机硬件业务（2021年彻底剥离）
  → 广告成为主要收入来源
  → 2020年启动VIP订阅模式

阶段三（2022–2023）：SaaS/订阅崛起
  → 2022年VIP订阅收入7.82亿元（+57.4%），SaaS收入4.63亿元（+1093.2%）
  → 订阅收入首次超过广告，成为最大收入来源
  → 广告收入约5.96亿元，退居第二

阶段四（2024–2025）：AI驱动全面商业化
  → "影像与设计产品"成为官方口径（以订阅为主）
  → 2024年该板块收入20.9亿元（+57.1%），占总收入62.4%
  → 2025年该板块收入29.5亿元（+41.6%），占总收入76.6%
  → AI Agent、Token/Credit消费模式兴起
```

### 2.2 收入结构详细对比（2022 vs 2023 vs 2024 vs 2025）

| 收入板块 | 2022年（亿元） | 占比 | 2023年（亿元） | 占比 | 2024年（亿元） | 占比 | 2025年（亿元） | 占比 |
|---------|-----------|------|-----------|------|-----------|------|-----------|------|
| 影像与设计产品（订阅为主） | 7.82¹ | 37.5% | 13.3 | 49.3% | 20.9 | 62.4% | 29.5 | 76.6% |
| 广告业务 | 5.96 | 28.6% | 7.6 | 28.1% | 8.5 | 25.4% | ~稳定 | 下降 |
| 美业解决方案（SaaS） | 4.63² | 22.2% | 5.7 | 21.1% | 3.8 | 11.4% | — | — |
| 其他/IMS | 2.45 | 11.7% | — | — | 0.17 | 0.5% | — | — |

> ¹ 2022年VIP订阅业务收入；² 2022年SaaS及相关业务收入（含美业SaaS）
> 注：2024年起美图对业务分部进行了重新分类，"影像与设计产品"涵盖原VIP订阅+部分SaaS；美业解决方案单列

### 2.3 关键收入结构转折点

- **~2022年：** VIP订阅收入（7.82亿）首次**超过**广告收入（5.96亿），成为第一大收入来源
- **2023年：** 影像与设计产品收入（13.3亿）达到广告收入（7.6亿）的**1.75倍**，差距持续拉大
- **2024年：** 影像与设计产品占比突破**60%**（62.4%），彻底确立以订阅为核心的模式
- **2025年：** 影像与设计产品占比达**76.6%**，订阅模式占据绝对主导

## 三、当前商业模式详解

### 3.1 VIP订阅业务（核心收入引擎）

**规模与增长：**

| 指标 | 2022年底 | 2023年底 | 2024年底 | 2025年底 | 2026年Q1 |
|------|---------|---------|---------|---------|---------|
| 全球付费订户（万） | 560 | 911 | 1,261 | 1,691 | 1,790 |
| 同比增长 | — | +62.3% | +38.4% | +34.1% | +30.2% |
| 订阅渗透率 | ~2.3% | ~3.6% | ~4.7% | 6.1% | — |
| 月活用户（亿） | 2.43 | 2.50 | 2.66 | 2.76 | — |

**订阅业务拆分（2025年）：**
- **生活场景产品（Applications for Leisure）：** 订户1,475万（+30.3% YoY），订阅率5.9%
  - 核心产品：美图秀秀、美颜相机、Wink
  - 美图秀秀连续10年中国修图类App用户规模第一
  - 美颜相机"AI衣橱"功能获全球2,300万+新用户
  - Wink全球MAU超4,000万
- **生产力工具（Applications for Productivity）：** 订户216万（+67.4% YoY），订阅率9%
  - MAU达2,400万（+9.1% YoY）
  - 占影像与设计产品收入的19%

**ARPU趋势：**
- 管理层明确表示"ARPU扩张预计将成为越来越重要的增长驱动力"
- 海外高ARPU地区（欧美、东亚）新订户增速加快，有望提升整体ARPU
- 2026年Q1生活场景产品收入增长35.5%（高于订户30.2%增长），暗示ARPU在提升

### 3.2 生产力工具/SaaS业务

## 四、AI商业化进展（2023–2026）

### 4.1 AI技术底座：MiracleVision（奇妙大模型）

| 时间节点 | 版本/里程碑 | 说明 |
|---------|-----------|------|
| 2023年6月 | MiracleVision 发布 | 15周年庆典发布，自研AI视觉大模型 |
| 2023年10月 | V3.0 | 100天迭代，支持电商/广告/游戏/动画/影视五大行业 |
| 2024年1月 | 备案完成 | 通过《生成式人工智能服务管理暂行办法》备案 |
| 2024年6月 | V5.0 (DiT架构) | 自研DiT技术架构，参数规模大幅提升 |
| 2025年 | 持续迭代 | 与阿里通义万箱系列模型合作；引入"模型容器"方法 |

### 4.2 AI商业化路径

**路径一：AI功能 → 提升订阅转化**
- 2023年：每日处理数亿张图片/视频，**83%使用AI功能**
- AI功能（AI画像、AI动画、AI衣橱、AI雪景等）持续制造爆款，带动MAU和付费转化
- 订阅率从2022年~2.3%提升至2025年6.1%

**路径二：AI生产力工具 → 开辟B端收入**
- DesignKit 2024年单产品收入~2亿元，2025年继续高增长
- X-Design（海外版）2023年收入破亿（+229.8%）
- 生产力工具总订户从2024年底的~100万+增长至2025年底216万（+67.4%）

**路径三：Token/Credit消费模式（2025年新增）**
- 除订阅外，用户可按需购买AI Credits使用高级AI功能
- 2026年Q1数据：用户AI Credits消费量3月环比2025年12月增长59%
  - Kaipai: +360%
  - RoboNeo: +316%
  - Designkit: +107%
  - Vmake: +78%

**路径四：AI Agent → 产品形态跃迁**
- 2025年：AI Agent全面集成到美图产品矩阵
- RoboNeo推出"Agent Teams"，多Agent协作完成端到端任务
- Designkit的Agent功能成为收入增长第一驱动力

### 4.3 全球化AI商业化

| 海外MAU（万） | — | 9,451 | 10,000+ |

## 六、商业模式总结与展望

### 当前商业模式画像（2025–2026）

```
美图公司商业模式（2025年）

┌──────────────────────────────────────────────────┐
│               影像与设计产品（76.6%收入）           │
│                                                    │
│  ┌──生活场景──┐    ┌──生产力工具──┐               │
│  │ 美图秀秀    │    │ DesignKit    │               │
│  │ 美颜相机    │    │ Kaipai       │               │
│  │ Wink       │    │ RoboNeo      │               │
│  │ 订户1,475万 │    │ Vmake/WHEE   │               │
│  │ 渗透率5.9%  │    │ 订户216万     │               │
│  └────────────┘    │ 渗透率9.0%    │               │
│                    └──────────────┘               │
│                                                    │
│  变现模式：VIP订阅 + AI Credits/Token + 功能买断    │
├──────────────────────────────────────────────────┤
│  广告业务（~20%收入）                              │
│  开屏广告、信息流广告、品牌合作                      │
├──────────────────────────────────────────────────┤

│  MeituEve皮肤分析、Meidd ERP                       │
└──────────────────────────────────────────────────┘
```

### 核心增长逻辑

1. **订阅渗透率提升空间大：** 当前6.1%的订阅率，对比Spotify（~25%）、YouTube Premium仍有巨大空间
2. **ARPU扩张：** 海外高ARPU地区用户占比提升 + 生产力工具9%渗透率（高于生活场景5.9%）
3. **AI Credits消费爆发：** Token-based消费模式打破订阅ARPU天花板，2026年Q1已显现爆发趋势
4. **生产力工具第二曲线：** ARR 5.8亿，增速56.2%，B端变现空间广阔
5. **全球化第三曲线：** 海外MAU破1亿，多款产品全球登榜

### 关键风险

- 通用大模型（GPT/Sora等）对垂直应用的潜在替代风险（管理层认为"协同>替代"）
- 海外市场地缘政治与合规风险
- 利润率压力：AI推理成本、研发投入持续高位
- 2025年IFRS口径因非经营性因素波动大（可转债非现金费用5.12亿）
