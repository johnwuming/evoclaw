# task-0240 结论：基于 R-200 的因子迭代方案

> 依据：《R-200-量化因子进化中因子选择与效率提升的平衡问题调研》
> 场景：微盘股量化策略，自动因子进化引擎 10 轮实验（R6 峰值夏普 1.406 → R10 跌至 1.131，-19.6%）

## 一、核心诊断（问题是什么）

R6 之后夏普持续下滑的**根因不是过拟合，而是「因子污染 + 探索-利用失衡」**：

1. **过度探索**：R7-R10 持续无脑生成新因子入池，弱因子/冗余因子稀释了 R6 已形成的强因子组合信号
2. **利用不足**：没有在 R6 最优因子上做精细化调优，而是盲目扩张因子池
3. **因子污染机制**：新因子即使 IC>0，若 `IC_new < ρ·IC_avg`（与现有因子相关性高），组合 IC 必然下降——这是数学本质，不是玄学

## 二、迭代方案（怎么改）

按优先级分三批落地，**先止血、再治本、后预防**：

### 第一批：立即止血（下轮进化前必须做）

1. **SOTA 最优快照机制** ⭐核心
   - 每轮保存完整快照（因子集+权重+模型参数），维护历史最优指针
   - 连续 3 轮未超越 SOTA → 自动回滚到最优状态
   - 预期：R9 触发回滚到 R6，最大回撤从 19.6% 降至 ≈0%

2. **三重入库门槛**
   - 新因子必须**同时**通过：绝对质量（IC>0.025 且 ICIR>0.4）+ 冗余检验（与池内因子最大相关 <0.6）+ 增量贡献（加入后组合 IC 提升 >0.002）
   - 预期：~90% 的新生成因子被拒之门外，因子池保持精炼

### 第二批：治本（进化引擎架构调整）

3. **探索-利用调度器**（参考 RD-Agent 的 Thompson 采样）
   - 每轮智能选择动作：探索新因子 / 优化已有因子 / 权重优化 / 剪枝淘汰
   - 避免无脑探索，R6 后自动加大「利用」比例
   - 数据支撑：Bandit 调度 vs 随机选择，IC 0.0445→0.0532，ARR 8.97%→14.21%

4. **定期剪枝 + 正交化**
   - 每 3 轮系统性剪枝：弱因子淘汰（IC<0.015）→ 层次聚类去重（相关>0.7 每簇留 IC 最高代表）→ 对称正交化
   - 因子池规模控制在 **15-25 个**（微盘股维度灾难边界，Gu/Kelly/Xiu：30 个后边际增益骤降）

### 第三批：预防（长期机制）

5. **因子生命周期管理**
   - 全生命周期跟踪：trial → active → monitoring → retiring → retired
   - IC 较峰值下降 30% 触发监控，IC<0.01 自动退役（微盘股因子半衰期短，监控周期用周度）
   - 加 CUSUM 变点检测做衰减预警

6. **加权方式改为 ICIR 加权 + 贝叶斯收缩**（向等权收缩，兼顾稳健与差异）

## 三、落地顺序建议

| 阶段 | 动作 | 工作量 | 优先级 |
|------|------|--------|--------|
| 本周 | SOTA 快照 + 三重入库门槛 | 小（纯逻辑层） | P0 |
| 下周 | 剪枝/正交化模块 | 中 | P1 |
| 下下周 | Thompson 调度器 + 生命周期管理 | 中 | P2 |
| 持续 | ICIR 加权改造 | 小 | P2 |

## 四、关键数字速记

- 因子池目标：**15-25 个**（微盘股）
- 入库门槛：IC>0.025、ICIR>0.4、相关<0.6、增量IC>0.002
- 回滚触发：连续 3 轮未超 SOTA
- 剪枝周期：每 3 轮；退役阈值：IC<0.01 或较峰值跌 30%
- 验证方法：增量贡献用 Bootstrap 检验 ΔIC 显著性，不依赖正态假设
