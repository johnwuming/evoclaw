## 4. 设计决策（写进 R-252）

1. 干预 = 尺寸因子倾斜调制（因子形态）：zsize_mod(t) = m(t)·z_logmv(t)，ext_specs 换列，引擎零改动
   - F1 阶跃：m=1−λ_c·1[p>60]；F2 线性：m=1−λ_c·clip((p−40)/20,0,1)
   - 网格 T1-T4：{F1,F2}×{λ_c=0.5,1.0}，n_trials=4（=上限）
2. 判胜门槛（预登记）：
   - G1 危机段：W-crisis 2023-09-01→2024-02-29 MDD ≥ -8.57%（较在役 -9.57% 改善 ≥1.0pp；≈10.4% 相对）
   - G2 年化损耗：W-crowd ann ≥ 12.44%（在役 13.94% − 1.5pp）
   - G3 血统：W-full MDD ≥ -35.55% 且 W-crowd MDD ≥ -18.13%（恶化均 ≤2pp）；W-full 预期不变（>0.5pp 变动=实现缺陷警报）
   - G4 holdout：ann ≥ 24.24%（在役 25.74% − 1.5pp）且 MDD 恶化 ≤2pp
   - 门槛论证：ddc 先例改善/代价比 2.4-2.6pp MDD per pp 年化；本设计 1.0/1.5=0.67 更保守，匹配选股层弱预期；E1 high-low 差 -1.14pp/月×25% 高位月占比给损耗上限合理性
3. G0 对拍门：λ_c=0 必须 NAV 与在役逐位一致（引擎零改动的结构保证）
4. 选择规则：过全部门者中 W-crisis MDD 改善最大；tie → λ_c 小者 → F2 优先
5. 停止规则：4 点全败（任一门无过点）→ 方向三关闭不进 E3；换口径/扩网格=新预注册+post-hoc 标注
6. holdout：2024-07-01→2026-08-14（库惯例切点）；网格全部预注册=零调参；G2 含 holdout 月（80 月全窗）需明示披露
