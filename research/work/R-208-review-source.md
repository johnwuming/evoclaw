## 0. 执行摘要

**一句话诊断**：当前系统是"机构级流程图 + 个人级实现度 + 一条正在 FAIL 的数据管道"。治理框架设计（registry 五维冻结、防漂移三校验、审计样本段）已达到机构水准，但核心执行环节（数据、因子台账、门禁、可交易性、组合构建）停留在个人玩家水平，且存在**正在发生的运行事故**。

**重构目标**：把"机构级设计"推进为"机构级实现"。三条主线：

1. **P0 地基修复**（2 周）：数据管道自动化+双源校验、可交易性回测三件套、退市股历史池——在此之前产生的所有回测结论均需重新标定；
2. **P1 对抗验证**（4 周）：validator agent 独立复现、五门禁数值化上线、DSR 回溯、审计段切分修正——用角色分离替代自我验证；
3. **P2 组合构建**（1–2 季度）：简版风险模型+约束优化、容量管理、第二 alpha 族——突破 Grinold-Kahn 广度天花板，而不是在单一策略上继续堆第 9 个择时信号。

**重构前后对比**：

| 维度 | 现状（实测） | 重构后目标 | 批次 |
|---|---|---|---|
| K线更新 | 手动触发，当前停更 6 天（FAIL） | 交易日自动 cron + 双源校验 + paper 熔断 | P0 |
| 因子 IC 覆盖 | 72 因子仅 4 个有 IC（5.6%） | 100% 覆盖 + 月度体检 + 生命周期状态机 | P1 |
| 升级门禁 | 3 项简单系数比较，MDD 恶化仍可通过 | 5 项数值门禁 + 影子检验 + 参数平坦性 | P1 |
| 回测成本模型 | 单边 0.1%，无冲击，无一字板约束 | 佣金+印花税+冲击（ADV 平方根），一字板/流动性约束 | P0 |
| 幸存者偏差 | 无退市池（D9 待建），结论已产出 | 2006 年起可交易股票池全量重建，偏差量化 | P0 |
| 验证独立性 | 研究/验证同一套 agent 代码 | researcher/validator/risk 三角色代码路径隔离 | P1 |
| 组合构建 | 等权 Top-30，min_amt=0 | 三因子暴露约束优化 + ADV 容量约束 | P2 |
| 退市纪律 | risk-charter 待建 | 事前写死 + 独立于开发 + 页面只读 | P0/P1 |

## 2. 重构原则（六条，评审时逐条对照）

1. **地基优先于上层**：数据可信度是所有上游结论的前提。地基未验收前，冻结一切策略层迭代（进化管道 Step0 fail-fast 扩展到 paper daily）。
2. **对抗验证替代自我验证**：任何候选版本的回测结论，必须由独立代码路径（validator agent 从 registry spec 复现）复核；复现偏差超阈值即双双打回。
3. **可交易性内建于回测**：成本模型、涨跌停约束、流动性过滤是回测器的一等公民，不是后处理修正项。回测不可成交 = 回测不存在。
4. **单一事实源**：registry（版本五维冻结）+ experiment-ledger（试验台账，只追加）+ decision-log（ADR 决策记录）三位一体，任何页面展示与决策依据只能读这三处。
5. **退出纪律先于进攻策略**：risk-charter 由风控角色持有，开发流程不可修改；触发即动作，不允许"下次再说"。
6. **广度优先于打磨**：接受单策略 IR 天花板，资源投向第二 alpha 族与组合构建；新 alpha 判据是与现策略 PnL 相关 < 0.5。

└──────────────────────────────────────────────────────────────────────────┘

## 4. P0 地基修复（第 0 批，2 周，先于 R-207 全部 W 任务）

### 4.1 W0a 数据管道自动化与冗余（对应 E1）

**交付物**：

1. **K线采集 cron 化**：交易日 17:30 自动增量采集（当前手动触发是 E1 的直接原因）；采集失败连续 2 交易日 → 微信告警。
2. **双源交叉校验**：关键字段（收盘价/分红/股本）akshare × tushare 周度比对；差异率 > 0.5% 的字段进入人工抽检队列。
3. **paper daily 数据熔断**：Step0 的 fail-fast 语义扩展——data-health 任一 FAIL 且超 48h，paper daily 拒绝启动估值并告警（当前只拦进化管道，模拟盘正用 6 天前旧价运行，即 E1）。

**数据契约（L0 验收标准）**：

| 数据表 | 更新 | 校验规则 | PIT |
|---|---|---|---|
| 全市场日K | 交易日自动 | 新鲜度≤3 交易日；双源收盘价差异<0.1% | 复权因子随采随记 |
| 财务摘要 | 财报季自动 | 披露日字段非空率 100% | 披露日对齐（W6 三关提前） |
| 退市/ST 池 | 月度 | 2006 年起任一日可交易池可重建 | 核心（见 4.3） |
| 指数估值 | 周度 | 连续性：无缺口周 | 不适用 |
| 分红事件 | 随财务 | 近 12 月事件数同比波动 < 50% | 除权日对齐 |

**验收**：连续 4 周数据健康看板全绿；模拟盘在人为制造数据断档时自动停跑并告警（演练一次）。

### 4.2 W0b 可交易性回测三件套（对应 E5）

1. **流动性过滤**：`min_amt` 生效——直接采用 V3 实测结论（20 日均成交额 ≥ 500 万元；该变体 MDD -57.98% vs 基线 -79.11%，代价为年化 -0.6pp，值得）。写入 selection params，成为默认约束。
2. **一字板不可成交约束**：调仓日开盘一字涨跌停（当日高低价相等且量能为零或触板）的标的，顺延至下一个可成交日，成交价按次日 VWAP 近似；回测器内置。
3. **成本模型 v2**：

```
cost_per_side = 佣金(0.025%, 最低5元) + 印花税(卖出0.05%) + 冲击成本
冲击成本 = k × σ_daily × sqrt(单边金额 / ADV_20d)      # k=0.5 起步，TCA 数据回流后校准
```

   参数表落 `config/cost-model.json`；回测报告必须输出"成本占年化收益比"。

**验收**：v1.1 两腿回测用三件套重跑，输出修正后指标（**预期年化/回撤均变差——这是更接近真实的数字**）；新旧差值写入 decision-log 作为"可交易性折扣"基线。

### 4.3 W0c 退市/ST 历史池（R-207 的 W6 提前，对应 E2）

**数据结构**：`data/delisted-pool/delisted.parquet`（code, list_date, delist_date, st_periods[]），按月快照。

**重建方法**：交易所公告历史 + tushare 退市列表回补 2006–2026；ST 段从财报+公告双源交叉。

**验收**：
1. 任一历史日期 T 的"当日可交易池 = 现存池(T 时刻在市) − ST(T) − 停牌(T)"可重建；
2. v1.0/v1.1 基线在全量池重跑，输出新旧差值——**该差值即幸存者偏差的量化**，写入 decision-log；
3. 若年化差值 > 2pp（预期会超过），v1.x 系列 headline 全部加"未含退市池修正"水印直至重跑完成。

## 5. P1 对抗验证体系（4 周，与 R-207 W5 融合）

### 5.1 五门禁数值化上线（对应 E3）

取代现行 3 项系数比较（E3 中"MDD 恶化仍 PASS"的漏洞来源）。数值标准：

| 门禁 | 标准 | 数据来源 |
|---|---|---|
| G1 IS 全样本 ICIR 年化 | ≥ 0.5 | 因子 IC 台账 |
| G2 OOS（WF 段）ICIR | 达标且不显著劣于 IS（配对 t 检验 p>0.05） | WF 产物 |
| G3 与存量最高 \|ρ\| | < 0.7（超过需 Sharpe 显著更高破例） | 相关性矩阵 |
| G4 DSR | > 0.95（分母 n_trials 取全局台账） | 试验台账 |
| G5 经济学逻辑 | 一句话可解释，黑箱一票否决 | 假设卡 |

附加：影子统计检验（配对日度超额差 t + Jobson-Korkie）；参数平坦性（±10~20% 邻域扰动不剧烈劣化，Calmar 下降 < 30%）。

**关键规则**：G1–G5 由 R3 risk agent 持有判定代码；researcher 不可见判定实现（防止向门禁优化）。任何一项 FAIL 即拒绝，**不存在"回撤 FAIL 但夏普 PASS → PASS"式的或逻辑**（回撤约束独立成项：MDD 不得比 parent 恶化超过 2pp）。

### 5.2 Validator 独立复现 + DSR 回溯（对应 E7）

**角色分离实现**（利用现有多 agent 架构，成本低）：

- R2 validator agent 只读 registry 的五维冻结 spec（选股参数/择时配置/因子集/数据快照 hash/代码引用），**不读 researcher 代码**，用标准件（qlib/pandas 独立脚本）复现回测；
- 复现口径差：年化差 < 0.5pp、Sharpe 差 < 0.1 视为通过；超差 → 双双打回，差值写 decision-log；
- **DSR 回溯**：iter1–4 择时网格按 `abs×percentile×混合 × s1-s4 × mom × breadth` 枚举树重建真实 n_trials（预估 50+），对 i4_q3z 的 Sharpe 0.9146 做 DSR 折减，结果写入 registry.gate 字段；headline 对外统一用 WF 均值口径（12.05%）而非 IS 优值。

## 6. P2 组合构建与广度（1–2 季度，R-207 完全未覆盖的层）

### 6.1 简版风险模型与约束优化（取代等权 Top-N）

**风险模型（简版 Barra 思路）**：行业（申万一级）+ 市值 + 波动三因子暴露，协方差用 Ledoit-Wolf 收缩的样本协方差（月度重估）。

**优化问题**：

```
max   αᵀw                        # α = 选股得分（股息/ROE/ROA 复合）
s.t.  Σw = target_position       # 择时层输出的目标仓位
      wᵢ ≤ 5%                    # 单票上限
      |行业偏离| ≤ 10%            # 相对可选池
      |市值暴露| ≤ 0.5σ           # 风格暴露钉住
      wᵢ ≤ k × ADV_20d(i) / 组合规模   # 容量约束（k=10% 参与率）
      TE ≤ 12%                   # 跟踪误差上限（对 HS500 小盘基准）
```

求解器：cvxpy/scipy SLSQP 皆可（30 只规模毫秒级）。**这是比第 9 个择时信号边际价值高得多的一步**。

### 6.2 容量管理与拥挤度联动

- registry 版本对象新增 `capacity_est` 字段：`容量 = min(Σ ADV_20d × 参与率 × 建仓天数系数)`；
- W7 的微盘拥挤度 4 指标与容量联动：拥挤度 z>2 → 容量估计对折 + 降仓建议进 pending；
- **容量进版本准入**：模拟盘资金增长到 capacity_est 的 50% 时触发扩容量评估（不等到踩踏）。

### 6.3 第二 alpha 族路线图（突破广度天花板）

| 候选族 | 与现策略预期相关性 | 广度增益 | 优先级 |
|---|---|---|---|
| 大盘质量（盈利稳定性+低波） | 低（风格互补） | 池扩至沪深300 | 高 |
| 周频反转（微盘内） | 中（同池不同频） | 频率×4 | 中 |
| 可转债双低 | 低（资产类别互补） | 新资产 | 中 |
| 事件驱动（业绩公告漂移） | 低 | 事件维度 | 低（先观察） |

准入判据（§2 原则 6）：与现策略 PnL 相关 < 0.5 才算有效分散；每个新族走完整 P1 门禁。

### 6.4 TCA 起步（执行偏差记录）

模拟盘每笔记录：假设成交价 vs 次日实际可成交价（VWAP 近似），积累执行偏差分布——这是未来冲击成本模型 k 值校准的自有数据（顶尖基金的冲击模型正是这样滚出来的），10 万资金也要开始记。

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 重跑后 v1.x 指标大幅变差，心理落差导致放弃三件套 | decision-log 强制记录"可交易性折扣"，定性为"挤水分"而非"退化"；headline 口径统一 WF 均值 |
| 退市池重建不全（公告历史缺失） | 双源交叉 + 覆盖率指标（任一年度退市数 vs 已知退市数）公示；先上线已覆盖部分，标注置信区间 |
| validator 复现差长期 > 0.5pp | 差值本身是信号：数据快照或口径漂移——回到 W0a 排查，不允许"校准到一致" |
| 五门禁过严导致进化管道长期无 PASS | 预期行为（挤掉的是噪声候选）；影子区承接"统计合格但逻辑存疑"的候选观察 |
| 约束优化引入求解器 bug | 等权版本保留为 registry 中的可回退版本；优化版本先影子 3 个月 |
| agent 角色分离后开发效率下降 | researcher/validator 并行而非串行；validator 用标准件，边际成本低 |

### A. 指标口径统一定义

| 指标 | 口径 |
|---|---|
| ICIR 年化 | 月度 IC 均值 ÷ IC 标准差 × √12 |
| DSR | Deflated Sharpe Ratio（Bailey & López de Prado 2014, SSRN 2460551）；E[maxSR] 由全局 n_trials 计算 |
| n_trials | 试验台账累计条数（每候选每回测 +1），DSR 分母唯一来源 |
| WF OOS | 滚动窗口样本外拼接；OOS 窗口止于 2024-06-30（审计段纪律） |
| 可交易性折扣 | 同版本回测在"三件套开关前后"的年化差值（pp） |
| 容量 | min(Σ ADV_20d × 参与率上限 × 建仓天数系数)；拥挤度异常时取调整值 |
