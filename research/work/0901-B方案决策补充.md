# B 方案决策补充（09-01 晨会用）

## 1. B 拆分为 B1/B2（前置依赖：权重由谁定）
- B1：静态权重先建仓（金腿按 vC-0 快照 41.97% 一次性定），滚动化完成后转动态
- B2：等求解器滚动化（HP 日频数据接入）完成再建
- 时间差：B1 可 9 月中执行；B2 取决于日频管道改造进度
- **校准数据不对称：B1 有完整日频校准（R-392）；B2 无校准数据**——若 B1/B2 二选一，目前只有 B1 有数
- **建仓权重 = 设计权重 × 建仓时点 DDC 状态系数**：真金腿 DDC 2026-03-23 触发仍在减半中 → 若按引擎（模拟）状态建仓，实际比例约为设计的一半（~21% 而非 41.97%）；循环依赖（用模拟回撤定真实权重）已如实标注，决策包明示「实际建仓比例可能显著低于 41.97%」

## 4. 风险阈值（已核实，R-390）
- DDC 权威定义 = sleeve 回撤 ≤−20% → 减半（ddc_th20_rd50_rc5，R-336 §4.4 / R-318 F6 拍板）；ddc15 为历史候选已废弃
- runtime 历史模拟日频回撤 −21.31% → 击穿 DDC 1.31pp（若按废弃的 ddc15 则超 6.31pp）→ B 建仓后阈值口径以日频为准
- 月末采样低估系数非常数（2.06 倍仅为 a13+现金单配置），禁止外推
- 低估系数矩阵（R-390）：a13+现金 2.06× / a13 单腿 1.98× / 58/42 两腿 1.40× / 金单腿 1.28×
- a13 腿日频 MDD −33.55%（与 R-373 归因一致）深度击穿 DDC −20%（超 13.55pp），而月末采样 −16.95% 根本不触发 → 月末口径下 DDC「从未触发」是口径假象（P1 立项核心依据）
- B 配置历史校准已补算（R-392，n=3173 日，真金原始价重建静态 58/42、非信号路径——未接污染信号）：a13 腿 DDC 仅 1 次触发（2015-06-29，减半 334 日）；真金腿 3 次（2014-11-07 / 2021-03-05 / **2026-03-23，当前仍处减半中**）；组合 MDD −22.88%→−17.66%（DDC 生效）
- **终值代价 −12.2% 口径**：终值相对差（6.758→5.933）；年化换算 = 无 DDC 15.7% → 有 DDC 14.6%，成本约 1.15pp/年（日历窗口推导，252 天折算则 16.4%→15.2%）
- **同口径确认**：与 −21.31%（R-388 ④d）同为 a13 引擎日频净值+静态权重+日频估值，差异仅在配置（58/42 真金 vs 60/40 现金）与再平衡时点标注（月初 vs 月末，运营近似）→「B 无风控比现状差 1.57pp」对比成立
- **DDC 单次触发警示**：a13 腿 13 年仅 1 次触发（2015 股灾），样本不足以评估常态风控效果（R-392 errata 待 0610 批次补注）
- **vol_target 8%±2pp 对 B 配置是常态超带**：带内仅 41.7%/47.3%，超上带 1089/1187 天；当前 rv20=11.18%、rv60=15.24% 均超带 → 8% 与该配置波动结构不匹配，列待确认首项
- 引擎信号路径的历史校准待 A2 清洁链上线后补算（0609 阶段二门槛）
